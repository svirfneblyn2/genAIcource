Architectural Separation

Top lane is asynchronous document indexing (hours/minutes). Bottom lane is synchronous user query response (sub-500ms). Both share storage and observability.

MATHEMATICAL FOUNDATION

Text Embeddings & Geometric Metric Spaces

How natural language is projected into continuous high-dimensional vector representations.

05 / 26
VECTOR GEOMETRY Unit L2 normalization simplifies cosine similarity to a single hardware-accelerated dot product.
ADVANCED GENAI | ARCHITECTURE TRACK

Mathematical Details

Show that when vectors are L2-normalized, ||u|| = 1 and ||v|| = 1. The denominator of cosine similarity disappears, reducing search to matrix multiplication (GEMV) on tensor cores.

Vector similarity is blind to permissions. Explain why pre-filtering (filtering before ANN search) is mandatory in enterprise multi-tenant systems.

SEARCH COMPLEXITY

Similarity Search: Exact kNN vs Approximate Nearest Neighbors

Trading 1% recall for orders-of-magnitude reduction in latency and compute complexity.

08 / 26
ANN COMPLEXITY At scale, exact kNN search O(N·d) is cost-prohibitive: enterprise search requires O(log N) ANN.
ADVANCED GENAI | ARCHITECTURE TRACK

Complexity Comparison

Show the math: 10M vectors at 1536 dims burns 15.3 billion FLOPS for a single query in exact search. ANN with HNSW drops latency from seconds to 3-5 milliseconds.

ALGORITHMIC DEEP-DIVE

Vector Indexing: HNSW Multi-Layer Skip Graph

Hierarchical Navigable Small World: Combining probabilistic skip-lists with proximity graphs.

09 / 26
HNSW ARCHITECTURE HNSW provides sub-5ms search: top sparse layers make long-range jumps, bottom layers route locally.
ADVANCED GENAI | ARCHITECTURE TRACK

HNSW Deep-Dive

Explain the multi-layer graph topology. Query starts at top entry point (Layer 2) with wide skips, then drops to Layer 1, and finishes in Layer 0 with fine-grained greedy routing.

MEMORY OPTIMIZATION

Vector Indexing: IVF Voronoi Cells & Quantization

Compressing vector memory footprints by 75% to 90% for massive 100M+ vector scale.

QUANTIZATION COMPACTION Scalar Quantization (SQ8) compresses vectors from 4 bytes to 1 byte with under 1% recall loss.

IVF and Quantization

Explain Voronoi cell partitioning (IVF). Explain how Scalar Quantization (float32 to int8) cuts RAM by 75%, and Product Quantization (PQ) cuts RAM by up to 95%.

CAPACITY PLANNING

Vector DB Sizing Math: Calculating RAM for 1M Vectors

Capacity Sizing Equation

RETRIEVAL PARADIGMS

Lexical vs Dense Retrieval: Why Neither Alone is Enough

BM25 keyword precision vs bi-encoder semantic abstraction: complimentary strengths.

12 / 26
HYBRID REASONING Dense embeddings blur exact codes and part numbers: lexical BM25 guarantees keyword precision.
ADVANCED GENAI | ARCHITECTURE TRACK

Complementary Strengths

Demonstrate why pure dense vector search fails on alphanumeric codes (Room B12, POL-SEC-402, 0x80070005). BM25 handles exact tokens; Dense handles semantic synonyms.

RANKING MECHANICS

Hybrid Fusion: Reciprocal Rank Fusion (RRF)

Combining disparate score distributions into a single mathematically calibrated ranking.

13 / 26
FUSION FORMULA Reciprocal Rank Fusion (k=60) merges sparse and dense rankings without score normalization.
ADVANCED GENAI | ARCHITECTURE TRACK

RRF Mathematics

Explain why we cannot simply add BM25 scores (0 to inf) and Cosine scores (-1 to 1). RRF uses ordinal rank positions with smoothing constant k=60, making it immune to scale calibration issues.

TWO-STAGE RETRIEVAL

Cross-Encoder Reranking: Two-Stage Pipeline Precision

Combining ultra-fast bi-encoder candidate retrieval with full cross-attention scoring.

14 / 26
RERANKING GAINS Bi-encoders fetch top-50 candidates in 15ms: a cross-encoder scores full joint attention to pick top-5.
ADVANCED GENAI | ARCHITECTURE TRACK

Two-Stage Retrieval

Bi-encoders encode query and document independently (fast, vector dot-product). Cross-encoders concatenate query + document into a single transformer with full cross-attention (slow, but captures deep token interactions).

CONTEXT ARCHITECTURE

BOUNDARY RULES Position critical evidence at prompt boundaries: anchor output schemas at the absolute end.

Attention U-Curve

Explain the Stanford empirical finding: facts in the center of long prompts suffer 30-50% retrieval drop. Mitigate by pinning high-scoring chunks to the top (Primacy) and schema rules to the bottom (Recency).
