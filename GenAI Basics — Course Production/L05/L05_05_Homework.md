## Цель задания

1. Своими глазами увидеть разницу между **T2V** (видео только из текста) и **I2V** (видео из готовой картинки + текста о движении).
2. Задать одно понятное движение камеры (облёт, наезд или «камера едет рядом»).
3. Удержать героя или товар из L04 одинаковым на протяжении клипа.
4. Принять клип по чек-листу из 6 пунктов и честно описать, где и почему модель ошиблась.

Оцениваем **осознанность, а не красоту**: видно ли, что вы понимаете, где и почему модель ошиблась.

## Выберите один из двух треков

### Трек А — товар
1. **Исходный кадр:** ваш одобренный пакшот из L04 (например, `D0_packshot.png` или `A3_details.jpg`).
2. **Что сделать:** промо-ролик около **5 секунд** (если сервис не даёт 5 с — ближайшая длительность, 4–6 с). Камера — **облёт (orbit)** или **наезд (dolly in)**, одно движение на клип.
3. **Требование:** форма товара, пропорции, цвет и надписи **не «плывут»**.

### Трек Б — курьер (кейс Glovo из L01 и L04)
1. **Исходный кадр:** ваш одобренный кадр курьера из L04 (например, `C2_rain.jpg`).
2. **Что сделать:** шот поездки около **5 секунд** — **камера едет рядом** с курьером (tracking shot); колёса крутятся вперёд.
3. **Требование:** лицо и форма — **как на референсе**. Логотипов и чужих брендов в кадре не добавляем: Glovo — только название учебного кейса.

## Какие сервисы можно взять (октябрь 2026)

Любые **два** сервиса, которые умеют image-to-video. Условия бесплатного доступа меняются часто — проверьте перед началом.

| Сервис / модель | Что важно для ДЗ | Бесплатно? |
|---|---|---|
| **Kling 3.0** (kling.ai, Kuaishou) | I2V, первый + последний кадр, Elements (2–4 референса); клип 3–15 с; звук | Есть ежедневные бесплатные кредиты (размер — по сторонним данным, **уточните**) |
| **Приложение Gemini / Flow** (Google) с **Veo 3.1** и **Gemini Omni** | I2V из картинки; Flow — первый + последний кадр, продление; Omni — черновик 360p | Flow — в подписках Google AI Plus / Pro / Ultra; бесплатный доступ к видео в приложении Gemini — **не подтверждено** |
| **Runway Gen-4.5** | I2V (первый кадр); камера словами или настройками; на Runway доступны и другие модели (Veo, Kling, Seedance, Wan, Hailuo) | Gen-4.5 — на платных планах; пробные кредиты — **не подтверждено** |
| **Luma Ray3.2** (Dream Machine) | I2V, клип 5 или 10 с, дешёвый черновик 360p; **без звука**; движения камеры — готовые «концепты» (Orbit left/right и др.) | Бесплатный тариф — **не подтверждено** |
| **Hailuo H3** (MiniMax) | I2V, первый + последний кадр, клип 5–15 с; модели Hailuo также есть в Leonardo | Бесплатный тариф — **не подтверждено** |
| **Wan 2.2** (открытые веса, Alibaba) | локально через ComfyUI; модель TI2V-5B — 720p, 5 с, нужна видеокарта на 24 ГБ | Бесплатно, если есть своя видеокарта |
| **Veo 3.1 через API** (по желанию) | код как на слайде 14; Fast — $0.10/с, Lite — $0.05/с (720p) | **Платно**, бесплатного тарифа для Veo в API нет |

**Не используйте:** Sora — закрыта (приложение с 26.04.2026, API с 24.09.2026). ChatGPT видео не делает.

## Шаблон `video_qa.md`

```markdown
# Приёмка видео • Домашнее задание L05

| # | Пункт чек-листа | Сервис №1 | Сервис №2 | Комментарий (что и где, таймкод) |
| :- | :--- | :---: | :---: | :--- |
| 1 | **Руки и предметы** в контакте — не слипаются, не исчезают | ✓ / ✗ / частично | ✓ / ✗ / частично | |

| 5 | **Первый кадр** — совпадает с одобренным кадром из L04 | | | |
| 6 | **Стык шотов** — свет и цвет совпадают (если склеивали клипы; иначе — «не применимо») | | | |

### Сравнение с T2V
[2–3 предложения: что сломалось в 01_t2v_trap и почему I2V справился лучше или хуже]

[3–4 предложения: какой сервис лучше справился с вашей задачей и почему; что бы вы сделали иначе — другой кадр, другой промпт, другая камера]
```

## Как оцениваем (рубрика = чек-лист слайда 16)

| Что смотрим | Зачтено, если |
|---|---|
| Все 6 пунктов чек-листа заполнены для обоих I2V-клипов | у каждого пункта есть оценка, а у проблем — таймкод |
| Сравнение T2V vs I2V | видно, чем именно отличаются результаты и почему (кадр зафиксировал внешность) |
| Промпты | в `video_spec.md` есть все три промпта; в I2V-промпте есть камера, действие и детали движения |
| Вывод | объяснено, где и почему модель ошиблась и что вы бы поменяли |

Идеальное видео **не требуется**: клип с найденными и описанными ошибками засчитывается лучше, чем «красивый» клип без разбора.
