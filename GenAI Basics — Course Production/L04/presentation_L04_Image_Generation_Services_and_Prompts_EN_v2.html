Under the Hood • Two Ways to Draw

How Models Draw: Diffusion vs Autoregression

Diffusion: from noise, everywhere at once
  • Starts from pure noise and removes it over 20–50 steps across the whole image at once; the prompt steers every step.
  • Different seed = different noise = different image. Hence the studio knobs: seed, guidance, steps, negative prompt.
Who: Stable Diffusion / SDXL, FLUX, Midjourney, most studio models.
Autoregression: patch by patch, like text
  • An image is a sequence of patch tokens; the model predicts the next one, like the next word in a sentence.
  • The same multimodal LLM that reads the prompt does the drawing → strong at text, instructions and edits. Often a hybrid.
Who: GPT Image, Grok Aurora; Nano Banana — architecture not disclosed.
In practice: diffusion — sliders and seed; chat models — prompt as a spec and edits in words. The techniques in this lesson work for both.

Part 3 • Prompt Engineering • Slot Anatomy

Six Slots — What Controls What

Runnable slot prompt (copy & run) high scene control
Subject: a speckled cream ceramic mug of black coffee with steam, on worn oak counter in right third. Setting: empty Scandinavian coffee shop at 7 a.m., chairs up on tables, brass espresso machine on left. Camera: eye-level, 35mm lens, f/2.0, shallow depth of field. Lighting: low warm morning sunlight from left window, long soft shadows. Style: realistic editorial photography. Constraints: no text, no logos.
Negatives depend on the model
Gemini and GPT follow positive phrasing better: "empty coffee shop" instead of "no people". Negations via --no / negative prompt are for Midjourney and SD / FLUX in studios.
Instead of "cozy, 4k, masterpiece" — physical details: time, optics, light.
1 Subject — main object, texture, placement in frame (right third).
2 Setting — time and context: "7 a.m., chairs up" removes random people.
3 Camera — 35mm (natural, moderately wide angle), f/2.0 — soft bokeh.
4 Lighting — low light from the left adds volume and long shadows.
5 Style — editorial photo instead of a glossy 3D render.
6 Constraints — what to exclude: text, logos.

Part 4 • Control Methodology

Iterate in Loops — Never Reroll the Whole Dice

Engineering Refinement Template
Edit this image. Modify only object X to Y. Preserve: angle, lighting, background, and shadows. Do not change: surrounding room geometry.
  • One edit per step (equivalent to an atomic git commit).
  • Explicitly declare protected regions to preserve context.
  • After ~5–8 edits drift becomes visible — start a fresh chat from the best frame.

Part 5 • Programmatic Execution

Batch Generation via Code — Same SDK as L03

import csv
from google import genai
from google.genai import types
from PIL import Image

client = genai.Client()
ref = Image.open("packshot.png")

for row in csv.DictReader(open("catalog.csv")):   # ~50 products
    resp = client.models.generate_content(
        model="gemini-3.1-flash-image",
        contents=[ref, PROMPT_SPEC.format(**row)],
        config=types.GenerateContentConfig(
            response_modalities=["IMAGE"],
            image_config=types.ImageConfig(aspect_ratio="16:9")))
    for part in resp.parts:          # response = list of parts
        if part.inline_data:         # keep only the image
            part.as_image().save(f"{row['sku']}.png")
~50 cards in ~10 min for ~$2–3
Instead of a day of manual browser work: a product CSV → a generation loop. Roughly 10 s and $0.04–0.06 per image.
Don't take parts[0] blindly: the response may also contain text parts. Look for the part with inline_data.
10/90 in code: the model call is 5 lines. The rest is catalog parsing, prompt templating, retries and automated artifact checks.

Part 5 • Governance • Blast Radius

Technical Limitations & Production Boundaries

  • Anatomy & small text: fingers in crowds and long paragraphs still fail.
  • Detail drift: after ~5–8 consecutive edits, drift in faces and logos becomes visible.
  • Copyright: in the US a purely AI-generated image is not protected (Thaler: on 02.03.2026 the Supreme Court declined to hear the case). Disney / Universal v. Midjourney is ongoing.
  • Provenance: SynthID — an invisible watermark in the pixels (Google; OpenAI since 05.2026) + C2PA — signed metadata that is lost on a screenshot.

Takeaways • Bridge to Video

Four Principles of Visual AI Engineering

1. Tool to Match Task
Chat for concepts and text, studio for canvas and masks, API for batch automation.
2. Structure Over Freeform
6 explicit slots (Subject, Scene, Camera, Light, Style, Negatives) + Must-Have block.
3. Surgical Refinement Over Rerolls
Atomic "modify only X, preserve Y" commands outperform blind dice rolling.
4. Consistency via Visual Anchors
Master character sheet + 4–6 distinctive textural anchors preserve identity anywhere.
