## Цель

Показать на своей задаче три навыка урока:
1. переход от свободного промпта к структурному;
2. правку «измени только X, сохрани остальное»;
3. консистентность: один и тот же товар или персонаж в разных кадрах.

## Выберите трек

### Трек А — AI-фотосессия товара

1. **Мастер-кадр.** Сфотографируйте на телефон свой предмет на однотонном фоне (кружка, наушники, книга, рюкзак) или сгенерируйте пэкшот.
2. **Признаки товара.** Выпишите 4–6 признаков, которые нельзя менять (форма, цвет, материал, узор, пропорции, детали).
3. **Шот-лист из 4 кадров:** лайфстайл • флэтлей сверху • товар в руках • баннер с текстом (точная фраза в кавычках).
4. Каждый кадр: мастер-кадр как референс + признаки товара + новая сцена + камера и свет + строка «не меняй форму, цвет, узор и пропорции».

### Трек Б — персонаж-курьер (кейс курьера доставки Glovo из L01)

1. **Лист персонажа:** ваш курьер в 3–4 ракурсах на нейтральном фоне, 4–6 ярких примет-якорей (одежда, цвет сумки, прическа, аксессуар).
2. **Три сцены рабочего дня** (например: в пути, у двери клиента, перерыв). Лист — референс, приметы — словами в каждом промпте.
3. **Одна точечная правка** любой сцены: замена объекта или времени суток по шаблону «измени только X, сохрани остальное».

> Без логотипов и названий реальных брендов на картинках: бренд — это чужой товарный знак (красная зона светофора из урока).

## Критерии оценки

| Критерий | Что проверяем |
|---|---|
| Структура промпта | Видны слоты; есть обязательные детали и запреты |
| Разница свободный ↔ структурный | В `qa.md` перечислено, что модель решила сама |
| Консистентность | Товар или персонаж узнаваем во всех кадрах; приметы проверены по списку |
| Правка | Изменено одно, остальное сохранено (Трек Б) / товар не изменился при смене сцены (Трек А) |
| Воспроизводимость | Для каждой картинки есть сервис, модель, дата, промпт |
| Честность QA | «Уплывшие» детали записаны. Это наблюдение, а не минус |

## Подсказки

- Пишите промпт связным текстом по слотам, главное — в начале.
- Текст на картинке — в кавычках, со словом *exactly*, коротко.
- Одна правка за шаг. Если после 6–8 правок картинка «устала» — новый чат, лучшая версия как референс.
- Для персонажа яркие приметы (бирюзовый рюкзак, светоотражающая полоса) держатся лучше, чем «обычная куртка».
- Midjourney: параметры в конце промпта (`--ar 4:5 --s 100 --raw`), для правок — инструмент Edit.
- Leonardo.ai: используйте Canvas и Inpainting для точечной замены кистью, а Guidance Scale держите в диапазоне 7–9.
- ChatGPT / Gemini (Nano Banana): описывайте правку естественным языком («change only X, keep the rest»), модель отлично держит смысловой контекст сцены.
