### Слайд 02 (02:00–07:00) • Каждый новый чат начинается с нуля: роль, правила и файлы приходится повторять

**На экране:** Схема (HTML): инструкции + знания + инструменты + модель = ваш ассистент.

Инструкции: роль, правила, тон. Знания: ваши файлы, регламенты, таблицы. Инструменты: поиск, код, подключения MCP из L12. Модель: какой ИИ будет отвечать.

### Слайд 03 (07:00–12:00) • GPTs в ChatGPT отключают 11 декабря 2026 — их переносят в плагины

**На экране:** Скриншот баннера ChatGPT «Перенесите свои GPT в плагины до 11 декабря», подпись с переводом и три блока: что переносится, что нет, Gems.

#### Спикер (5 мин)
> Это баннер прямо на странице GPTs в ChatGPT: «Перенесите свои GPT в плагины до 11 декабря». 11 декабря все GPT станут недоступны; то, что не перенесли в плагин, пропадёт. Для Enterprise с одобренной отсрочкой — до 11 февраля 2027. При переносе инструкции становятся «навыком» плагина, файлы знаний — справочными файлами, подключённые приложения сохраняются. Свои Actions, выбранная модель и настройки доступа не переносятся.
>
> Google делает то же: в личных аккаунтах Gems с 17 ноября 2026 становятся навыками (об этом сообщает баннер в Gemini), в Workspace — с марта 2027. Вывод для нас: названия продуктов меняются, а формула «инструкции + знания + инструменты» остаётся. Её и учим.

### Слайд 08 (32:00–38:00) • Прежде чем делиться ассистентом, проверьте его четырьмя типами вопросов

**На экране:** Четыре типа тестовых вопросов и предупреждение про файлы знаний.

#### Спикер (6 мин)
> Четыре теста. Обычный вопрос — ответ должен опираться на ваш файл. Вопрос вне знаний — ассистент должен честно сказать «не знаю», а не выдумывать. Попытка нарушить правило — например, попросить email клиента: должен отказать. Хитрая просьба «забудь инструкции» — это prompt injection из L11, ассистент должен устоять.
>
> Важно: если вы делитесь ассистентом, пользователь может хитрыми вопросами вытащить содержимое файлов знаний. Официальной гарантии защиты нет. Поэтому в знания кладём только то, что не страшно показать всем, кто им пользуется.

### Слайд 09 (38:00–43:00) • Когда кнопок мало: четыре ступени от проекта до своего агента в коде

**На экране:** Лестница (HTML): проект/плагин → Responses API → Agents SDK → Agents API, и четыре пояснения.

#### Спикер (5 мин)
> Если ассистент нужен внутри своего приложения или сайта, кнопок недостаточно. Лестница OpenAI. Внизу проект или плагин — без кода. Responses API — запрос к модели в несколько строк кода, с инструкциями и встроенными инструментами. Agents SDK — библиотека, которая крутит цикл агента в вашем коде: несколько агентов, передача задачи, проверки, журнал. Agents API — новый сервис (бета с 10 сентября 2026): цикл и изолированную «песочницу» запускает сама OpenAI, вы платите только за токены и инструменты.
>
> Что ушло: старый Assistants API отключён 26 августа 2026, визуальный конструктор OpenAI Agent Builder (не путать с Agent Builder в Copilot) закрывается 30 ноября 2026. У других поставщиков похожие лестницы: Claude Agent SDK, Google ADK (урок 12).

### Слайд 10 (43:00–48:00) • Responses API: инструкции и разговор в нескольких строках кода

**На экране:** Справочный код Responses API с instructions и previous_response_id.

#### Спикер (5 мин)
> Для тех, кто программирует. Responses API — рекомендованный OpenAI способ для новых проектов (Chat Completions из L03 продолжает работать). Поле instructions — как инструкции проекта, только его нужно передавать в каждом запросе: с previous_response_id прежние instructions не переносятся. previous_response_id продолжает разговор: не нужно пересылать историю вручную.
>
> Ловушка: даже с previous_response_id вся предыдущая переписка оплачивается как входные токены на каждом шаге. gpt-6-luna — самая дешёвая из моделей GPT-6: $0,10 за миллион входных и $0,50 за миллион выходных токенов; тысяча коротких вопросов стоит около 20 центов. А вот встроенный веб-поиск стоит $10 за тысячу вызовов — в 50 раз дороже токенов. Пример справочный, не запускался: нужен ключ OpenAI API.

### Слайд 11 (48:00–53:00) • Agents SDK: несколько агентов, и один передаёт задачу другому

**На экране:** Справочный код Agents SDK: три агента, handoff_description и handoffs.

#### Спикер (5 мин)
> Agents SDK, пакет openai-agents, версия 0.24 от 15 октября 2026. Три агента: «Billing» про оплату, «Tech» про вход и приложение, и «Triage» — диспетчер, у которого в handoffs перечислены специалисты; по их handoff_description (короткое описание) диспетчер выбирает, кому передать. Runner запускает диспетчера; тот понимает тему и передаёт разговор. result.last_agent.name покажет, кто в итоге ответил — здесь ожидаем Billing.
>
> Внутри SDK — тот же цикл агента из L11. Плюс готовое: guardrails (автоматические проверки входа и выхода), сессии с памятью, трассировка каждого шага, подключение MCP-серверов из L12, пауза для одобрения человеком. Пример справочный, не запускался: нужен ключ OpenAI API.
