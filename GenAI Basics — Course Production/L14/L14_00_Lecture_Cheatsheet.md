## Ключевые факты (16.10.2026)
| Что | Факт |
|---|---|
| Streamlit | 1.66 (14.10.2026), Apache-2.0, Python 3.11+ |
| Запуск | `pip install streamlit`, `streamlit run app.py`, localhost:8501 (в офисной сети коллеги — по Network URL) |
| Агент | `streamlit skills` — официальные навыки для Claude Code, Codex, Cursor |
| Community Cloud | бесплатно, из GitHub; из публичного репозитория — публичное; приватное — только одно (приглашения по email); засыпает через 12 ч |
| HF Spaces | больше не бесплатно для Streamlit |
| AI Studio Build | приложение по описанию, приватно по умолчанию, ключ на сервере |
