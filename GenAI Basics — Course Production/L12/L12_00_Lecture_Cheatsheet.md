**Одной фразой:** MCP — открытый стандарт «разъёма», по которому один сервер с инструментами работает во многих ИИ-приложениях; подключайте только проверенные серверы, давайте минимум прав и читайте запросы разрешения; фреймворк агентов берите, когда шагов много.

## Термины
| Термин | Простыми словами |
|---|---|
| MCP | стандарт подключения ИИ-приложений к инструментам и данным |
| Хост | приложение, где вы работаете с ИИ (Claude, ChatGPT, VS Code) |
| Сервер MCP | программа, которая даёт инструменты, ресурсы и промпты |
| Коннектор | так Claude называет подключённый MCP-сервер |
| Локальный / удалённый сервер | программа на вашем компьютере / адрес в интернете с входом |
| Tool poisoning | спрятанная команда в описании инструмента |
| Фреймворк агентов | библиотека, которая крутит цикл агента: шаги, память, подтверждения |
| A2A | стандарт общения агентов разных компаний |

3. Число серверов в реестре, новости MCP (спецификация, фонд).
4. Версии фреймворков.
