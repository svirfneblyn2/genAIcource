## Живое демо (слайд 16)

1. Новый чат → «+» → Add files → `tickets_ru.csv`. Текст:
   ```
   Сделай дашборд для руководителя поддержки: что разобрать первым на утренней планёрке? Email клиентов не показывай.
   ```
2. Проверить вслух: срочное наверху (T-110 — P1 без ответственного), email нет, цифры сходятся с файлом (11 открыто, 4 срочных, 2 без ответственного).
3. В том же чате:
   ```
   Сделай из этого 3 слайда для планёрки.
   ```

Если результат не нравится — просите точно: «перенеси срочные без ответственного наверх», а не «сделай лучше».

## Демо-проект (слайд 17)

Projects → New project «Демо L09: поддержка курьеров». Instructions:
```
Ты помощник руководителя поддержки курьерской службы «Быстро».
- Отвечай кратко, по-русски.
- P1 — срочно, P2 — обычно, P3 — может подождать.
- Никогда не показывай email и телефоны клиентов.
- Данные бери из файла tickets_ru.csv в этом проекте.
```
Context → добавить `tickets_ru.csv`.
