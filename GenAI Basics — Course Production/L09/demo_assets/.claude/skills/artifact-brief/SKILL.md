---
name: artifact-brief
description: Create and review Artifact Build Briefs for small operational dashboards and interactive learning artifacts.
---

Use this skill when the user wants to create a Claude Artifact for an operational or educational workflow.

Process:
1. Identify the user, decision, source data, output type, constraints, privacy risks, and acceptance tests.
2. Draft a compact Artifact Build Brief.
3. Ask for missing required inputs before generating the artifact.
4. After the first artifact draft, run the acceptance tests and propose targeted revisions.

Do not publish or share artifacts unless the user explicitly confirms the intended audience and data sensitivity.
