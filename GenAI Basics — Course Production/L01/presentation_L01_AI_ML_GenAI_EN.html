Antipattern • Engineering Sobriety
10 / 21

The Hype Trap: Why "AI First" Wastes Enterprise Budgets

Forcing an LLM into every problem guarantees high latency, uncontrollable costs, and fragile outcomes:

ANTIPATTERN
“Let's hook an LLM into the accounting ledger!”
• Latency: 3 seconds wait time vs 2 milliseconds in SQL.
• Cost: $0.03 per invocation vs $0.000001 in conventional code.
• Accuracy: 95% vs 100% (5% calculation errors will bankrupt a business).
ENGINEERING MINDSET
“Problem First: Classify the Task Class First”
• Strict formulas & deterministic rules? ➔ Conventional code (100% guarantee).
• Historical tabular numbers & trends? ➔ Classical ML (speed & statistical rigor).
• Unstructured text, language & meaning? ➔ Generative AI (governed by human oversight).
Golden Rule: If a problem can be solved in 5 lines of code — calling an LLM is strictly prohibited.

Generation Mechanics • Probabilities
13 / 21

Under the Hood: “T9 on Steroids” & Probabilities

An LLM is an autoregressive calculator for the next token probability distribution:

INPUT CONTEXT (PROMPT):
“The capital of France is [ ? ]”
NEXT TOKEN PROBABILITY DISTRIBUTION:
Paris
96.4%
a city
2.3%
croissant
0.01%
Temperature Parameter
Temperature = 0.0 (Strict / Greedy):

Always selects the highest-probability token. Ideal for JSON schemas, factual extraction, and code.

Temperature = 0.8 (Creative):

Samples with controlled variability. Ideal for brainstorming, creative copy drafts, and storytelling.

Engineer's Rule: Model output represents statistical co-occurrence patterns in training data, not logical conscious reasoning.

17 / 21

Blast Radius Spectrum & Human-in-the-Loop

Model autonomy must be strictly inversely proportional to the cost and damage of an error:

LOW RISK • GREEN ZONE
Drafts & Creativity
• Summarizing lengthy articles
• Brainstorming ideas & email drafts
• Internal documentation search

Autonomy: Full. A hallucination costs $0 and harms no one.
MEDIUM RISK • YELLOW ZONE
Coding & Data Preparation
• IDE code autocompletion (Copilot)
• Initial Pull Request review
• Customer ticket categorization

Autonomy: Co-pilot. Human always verifies before merging.
HIGH RISK • RED ZONE
Finance, Prod & Legal
• Processing payments & invoices
• Legal contracts & binding terms
• Autonomous production deployments

Autonomy: Prohibited. Model only prepares advisory drafts.
Safety Principle: The higher the cost of failure, the stricter the Human-in-the-Loop gate.

Engineering Decision Tree: Do You Actually Need GenAI?

An algorithmic filter before writing project code. Route every user requirement through 4 questions:

01
Can the task be solved by deterministic algorithms, regex, or structured SQL?
YES ➔ Write conventional code
02
Does the problem require numeric predictions on historical tabular data (churn, demand, prices)?
YES ➔ Train classical ML
03
Does the task involve unstructured text, semantic understanding, code, or creative synthesis?
YES ➔ Apply Generative AI
04
Is 100% accuracy mission-critical, and is a Human-in-the-Loop review gate architected?
Validation plan required
Engineering Maturity: Do not solve problems with a sledgehammer when facing a screw.
