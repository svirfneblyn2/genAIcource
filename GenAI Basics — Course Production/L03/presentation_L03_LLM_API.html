ПРАКТИКА В БРАУЗЕРЕ
GENERATE_CONTENT_STREAM

Стриминг в коде: Разбираем потоковую генерацию

Метод `generate_content_stream` отдает текст порциями по мере вычисления, убирая ожидание

# Включаем живой поток токенов (Server-Sent Events): response = client.models.generate_content_stream( model="gemini-3.5-flash", contents="Объясни стриминг в 2 предложениях." ) # Выводим кусочки текста в консоль без буферизации: for chunk in response: print(chunk.text, end="", flush=True)
Что такое `chunk`?
Микро-пакет данных из сокета, в котором летит не весь документ, а маленькая дельта — 1 или 2 только что сгенерированных токена.
Зачем `flush=True`?
Принудительно сбрасывает буфер терминала или браузера, заставляя буквы появляться на экране немедленно с эффектом пишущей машинки.
Когда стриминг НЕ нужен?
Для фоновых скриптов, очередей задач и парсинга в JSON стриминг вреден. Используйте синхронный вызов для атомарного ответа.

СВЯЗКА С УРОКОМ 02

От чата к коду: Перенос XML и One-Shot из Урока 02 в API

Знания прошлых уроков становятся параметрами SDK: системная инструкция, XML-теги и детерминированность

from google.genai import types # 1. Системная роль вынесена в конфигурацию (защита от взлома промпта) config = types.GenerateContentConfig( system_instruction="Ты строгий аудитор. Извлекай факты без вежливости.", temperature=0.0 # 0.0 = максимальный детерминизм ) # 2. XML-каркас и One-Shot пример из Урока 02 внутри строки: prompt = f""" <context>Входящая рабочая рекламация</context> <rules>Извлеки сумму ущерба и отдел</rules> <example> <input>Списали 500$ по ошибке в бухгалтерии</input> <output>отдел: биллинг | сумма: 500$</output> </example> <document>{raw_text}</document> """ response = client.models.generate_content( model="gemini-3.5-flash", contents=prompt, config=config )
1. `system_instruction` в параметрах
В коде системная роль не смешивается с текстом пользователя. Это физически защищает модель от инъекций (Prompt Injection) со стороны злоумышленников.
2. XML-теги внутри f-строк
Теги <context>, <rules> и <document> четко разделяют инструкции от сырых входящих данных любого объема.
3. One-Shot + `temperature=0.0`
Один эталонный пример в промпте и нулевая температура полностью исключают лишнюю «вежливость» модели и гарантируют одинаковый результат при каждом запуске.

ПРАКТИКА В БРАУЗЕРЕ
ГАРАНТИРОВАННЫЙ JSON

Практический пример: Разбор входящего письма в JSON

Параметр `response_mime_type="application/json"` и температура 0.0 для жесткого контракта данных

import json from google.genai import types # Жесткий режим: модель физически не может вернуть ничего, кроме JSON config = types.GenerateContentConfig( response_mime_type="application/json", temperature=0.0 # Ноль фантазии, строгий детерминизм ) prompt = """ Разбери входящую заявку в JSON: { "category": "billing" | "technical" | "general", "urgent": true | false, "amount_usd": float } Заявка: Срочно! С карты дважды списали $450 за подписку, верните деньги! """ response = client.models.generate_content( model="gemini-3.5-flash", contents=prompt, config=config ) # Безопасно парсим валидный JSON в словарь Python: data = json.loads(response.text) print(data["category"]) # -> "billing" print(data["amount_usd"]) # -> 450.0 print(data["urgent"]) # -> True
Что произошло?
Эмоциональное неструктурированное письмо клиента за 1 секунду превратилось в четкую карточку с готовыми данными.
Зачем `temperature=0.0`?
Для извлечения цифр и категорий фантазия модели опасна. Нулевая температура гарантирует максимальную детерминированность.
Куда идут данные?
Поле amount_usd сразу идет в учетную систему, а срочная жалоба летит в финотдел без участия ручного оператора.

СЕТЕВЫЕ СБОИ

Что может пойти не так: 4 частые сетевые ошибки

Сеть обрывается, облака сбоят, а квоты исчерпываются. Как софт реагирует на ошибки

401 UNAUTHORIZED
Неверный ключ
Ключ скопирован с лишним пробелом, отозван или не задан в переменных. Решение: перепроверить значение ключа.
429 RATE LIMIT
Превышен лимит
Слишком частые запросы в минуту или закончился баланс кредитов. Решение: пауза и экспоненциальный откат (Backoff).
500 / 503 ERROR
Сбой провайдера
Перегрузка в дата-центре OpenAI или Google. Решение: 1–2 автоматических повтора или переход на резервную модель.
TIMEOUT
Зависание сети
Пакеты застряли по дороге. Без параметра timeout=30.0 скрипт может зависнуть намертво.
🛡️
Встроенные ретраи: Официальный SDK уже содержит встроенную логику повторов на ошибки 429 и 500. Вам не нужно писать сложные циклы руками.
