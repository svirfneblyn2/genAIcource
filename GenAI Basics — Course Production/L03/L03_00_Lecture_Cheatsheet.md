### Часть 1: Как устроено LLM API под капотом (00:00 — 55:00)

* **Слайд 01 (00–04 мин) • Титул:** LLM API с Python. Главная мысль: LLM — это не «сайт» и не «магия», а удаленный облачный HTTP-сервер, принимающий токены и возвращающий вероятности. Наша цель — обернуть вероятностный вывод в надежный программный контракт. Опрос в чат: кто уже пробовал вызывать API (1) или пока только чатился в браузере (2)?
* **Слайд 02 (04–08 мин) • Дорожная карта (Степпер):** Завершение Модуля 1 (L01–L03). Вызов через API — это фундамент: без него нельзя передавать изображения в Модуле 2, вызывать инструменты в Модуле 5 или строить автономных агентов в Модуле 6.
* **Слайд 03 (08–13 мин) • Архитектура взаимодействия (Схема потока):** Почему модель не живет внутри вашего ноутбука. Ваше приложение (Excel/Python/бэкенд) $	o$ HTTPS POST в шлюз API Gateway (проверка авторизации и квот) $	o$ Кластер GPU дата-центра (генерация токенов) $	o$ Ответ по проводу.
* **Слайд 04 (13–17 мин) • Анатомия HTTP-запроса (C4-диаграмма):** Сквозной путь сетевого пакета. Граница REST API Boundary (пунктир): слева — код студента, справа — закрытая инфраструктура провайдера с GPU.
* **Слайд 05 (17–22 мин) • Зачем нужен SDK (Защитный слой):** Сравнение двух подходов. Без SDK: ручные сокеты и сырой JSON приводят к авариям на сетевых сбоях и ошибках 429. С SDK: библиотека берет на себя ретраи, Keep-Alive, типизацию IDE и безопасный парсинг.
* **Слайд 06 (22–27 мин) • Первый вызов: Google AI Studio ➔ Colab (Код):** Запуск в браузере по кнопке ▶ Play. Мост из веб-песочницы Google AI Studio (`aistudio.google.com`): настроили промпт, нажали **«Get Code»** и запустили в Colab через защищенный сейф `userdata.get('GEMINI_API_KEY')` без ввода паролей и без показа на экране. Актуальная модель 2026: `gemini-3.5-flash` (15 RPM бесплатно).
* **Слайд 07 (27–31 мин) • Анатомия ответа (Электронный чек):** Что вернул сервер: `response.text`, `finish_reason` (`STOP` — штатно, `MAX_TOKENS` — исчерпан лимит токенов), объект `usage_metadata` (`prompt_token_count`, `candidates_token_count`, `total_token_count` — аудит квот и бюджета).
* **Слайд 08 (31–35 мин) • Безопасность API-ключей (Гигиена):** Ключ — это кредитная карта с прямым списанием баланса. Боты сканируют публичный GitHub за секунды. Стандарт: файл `.env`, обязательная запись в `.gitignore`, в Colab — сейф Secrets 🔑.
* **Слайд 09 (35–40 мин) • Стриминг: Физика и UX (Схема):** Блокирующий вызов (5 секунд гнетущей тишины) против мгновенного появления первого токена (TTFT = 200 мс) через Server-Sent Events (SSE). Стриминг меняет психологию ожидания у живого пользователя.
* **Слайд 10 (40–44 мин) • Стриминг в коде (`generate_content_stream`):** Как потоковый генератор выдает дельты текста. Цикл: `for chunk in response: print(chunk.text, end="", flush=True)`. Зачем нужен `flush=True` и когда стриминг НЕ нужен (фоновые очереди и запись в БД).
* **Слайд 11 (44–48 мин) • Мост с Уроком 02: Промпт-инжиниринг в коде (XML, One-Shot):** Как знания прошлых уроков становятся параметрами SDK. Системная роль в `system_instruction` (защита от Prompt Injection), XML-теги `<context>`, `<rules>`, `<document>` для четкого разграничения данных, и One-Shot пример с `temperature=0.0` для 100% повторяемости.
* **Слайд 12 (48–51 мин) • Структурированный вывод (Constrained Decoding):** Аппаратная гарантия формата. Сервер во время генерации накладывает грамматическую маску на токенизатор, обнуляя вероятности недопустимых символов. 100% синтаксическая строгость.
* **Слайд 13 (51–55 мин) • Практический пример: Триаж входящих в JSON (Код):** Параметр `response_mime_type="application/json"` и `temperature=0.0` на `gemini-3.5-flash`. Превращение эмоциональной жалобы клиента на двойное списание $450 в строгие поля словаря (`category`, `amount_usd`, `urgent`).

### Часть 2: Надежность, ландшафт библиотек и домашка (60:00 — 90:00)

* **Слайд 15 (60–65 мин) • Сетевые ошибки (Что может пойти не так):** 
  - `401 Unauthorized` — неверный или отозванный ключ.
  - `429 Rate Limit` — превышен лимит вызовов или исчерпан баланс. Экспоненциальный откат (Backoff).
  - `500 / 503 Provider Error` — временная перегрузка дата-центра Google/OpenAI.
  - `Timeout` — зависание сокета. Параметр `timeout=30.0` предотвращает паралич приложения. Официальный SDK берет ретраи на себя.
* **Слайд 16 (65–70 мин) • Ландшафт библиотек Python AI (3 слоя):** 
  - Слой 1: Низкоуровневый HTTP (`requests`, `curl`).
  - Слой 2: Официальные SDK вендоров (`google-genai`, `openai`, `anthropic`) — фундамент любого инженера.
  - Слой 3: Высокоуровневые оркестраторы (`LangChain`, `LlamaIndex`) — подключаются, только когда базовая библиотека исчерпала свои возможности.
* **Слайд 17 (70–74 мин) • Матрица моделей 2026 (OpenAI vs Claude vs Gemini):**
