## 1. Objectives

Transition prompting techniques from chat interfaces into automated production code:
1. **Deterministic Data Contracts:** Configure constrained decoding via `response_schema` (Pydantic / Structured Outputs) to mathematically prevent JSON parsing errors.
2. **Untrusted Data Isolation:** Wrap dynamic content in XML boundary tags (`<transcript>`, `<user_comment>`) to defend against instruction override and prompt injection.
3. **Telemetry and Unit Economics:** Inspect `usage_metadata` (`prompt_token_count`, `candidates_token_count`, `thoughts_token_count`) and calculate exact cost per 1,000 requests.
4. **Secrets Hygiene:** Manage credentials via Colab Secrets (`userdata.get('GEMINI_API_KEY')`) ensuring zero leaked tokens in source control.

## 3. Assignment Tracks (Select One or Both)

Completing either track satisfies the assignment. Completing both tracks earns maximum grade.

### Track A: Data Contract with Structured Output (Step 1.3)

*Scenario:* Automated support ticket triage pipeline requiring deterministic database ingestion.

1. **Ticket Input:** Prepare a realistic support ticket or use one of the samples below. **Sanitize all Personal Identifiable Information (PII):** remove customer names, payment card numbers, phone numbers, and physical addresses.
   * *Sample 1 (Billing):* `"URGENT! My card was charged $450 twice for the annual subscription. Refund the duplicate today."`
   * *Sample 2 (Technical):* `"App crashes every time I tap Checkout on iOS 18. Cart total is $120.50. Fix this immediately."`
2. **Execute Step 1.3:** Insert sanitized text into `customer_email`.
3. **Schema Definition:** Inspect `TicketTriage` (Pydantic model). Optionally extend with 1-2 custom fields (e.g. `language: str`, `suggested_action: str`).
4. **Validation:** Execute the cell and verify that `resp_json.parsed` produces a validated Python object with zero parser errors. (The pre-loaded `TicketTriage` schema in the notebook validates three fields: `category` (`billing` | `technical` | `general`), `urgent` (`bool`), and optional `amount_usd`).

### Track B: Prompt Patterns on Video Transcript (Step 6)

*Scenario:* Generating publication deliverables (executive summary, chapter timestamps, high-CTR titles) from raw video transcripts with injection protection.

1. **Transcript Input:**
   * **Option A (Instant Run):** A realistic 300-word engineering post-mortem transcript (PostgreSQL connection pool outage) is already pre-loaded into cell 47. You can execute it immediately without searching for external videos.
   * **Option B (Your Own YouTube Video):**
     1. Open any technical video on YouTube.
     2. Under the video title, inside the description box, click `...more` (or `Show more`).
     3. Scroll to the bottom of the description box and click `Show transcript`.
     4. Copy text from the transcript sidebar and paste it into `my_transcript`.
2. **Define Task:** Customize `my_task` in Step 6 (e.g. *"Summarize 5 architectural decisions and propose 3 titles under 60 characters"*).
3. **Boundary Verification:** Verify transcript is isolated inside `<transcript>...</transcript>` tags with system instruction declaring it untrusted data.
4. **Execute Call:** Store output in `my_response`.
