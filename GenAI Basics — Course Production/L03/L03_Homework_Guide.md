## 3. Треки задания (выберите один или оба)

### Трек А. Data Contract: Structured Output для тикетов (Шаг 1.3)

*Сценарий:* бэкенд службы поддержки принимает неструктурированные письма клиентов и раскладывает их по строгой схеме для передачи в CRM/базу данных.

1. **Подготовьте обращение:** возьмите реальное или реалистичное рабочее письмо/тикет поддержки (жалоба на списание, баг в приложении, запрос возврата). **Удалите все персональные данные (PII):** имена, номера карт, реальные телефоны и адреса.
2. **Вставьте текст в `customer_email`** в ячейке **Шага 1.3**.
3. **(Опционально) Расширьте схему `TicketTriage`:** добавьте 1–2 поля при необходимости (например, `language: str`, `suggested_action: str`, `affected_service: str`).
4. **Выполните ячейку:** убедитесь, что API вернул валидный JSON, а SDK распарсил его в объект `triage` (`resp_json.parsed`) без ошибок схемы.

```python
class TicketTriage(BaseModel):
    category: Literal["billing", "technical", "general"]
    urgent: bool
    amount_usd: float | None
    # Ваши дополнительные поля (опционально)
```

### Трек Б. Промпт-паттерны на реальном транскрипте (Шаг 6)

*Сценарий:* генерация публикации (выжимка, таймкоды, заголовки, идеи для Shorts) на основе реального видеоматериала с защитой от сбоев.

1. **Возьмите транскрипт любого YouTube-видео:**
   - Откройте видео на YouTube (технический доклад, туториал, подкаст).
   - Под плеером нажмите **… Ещё** (`…more`) ➔ прокрутите вниз ➔ **Показать текст видео** (`Show transcript`).
   - Скопируйте фрагмент (достаточно 300–800 слов с таймкодами или без).
2. **Вставьте текст в переменную `my_transcript`** в ячейке **Шага 6**.
3. **Сформулируйте задачу в `my_task`**, например:
   - *«Выдели 5 ключевых тезисов и предложи 3 кликабельных заголовка до 60 символов»*;
   - *«Составь список тем с таймкодами и идею для 1 короткого ролика (Shorts) с хуком»*.
4. **Проверьте защиту промпта:** убедитесь, что транскрипт обёрнут в XML-теги `<transcript>...</transcript>`, а системная инструкция трактует его исключительно как неисполняемые данные.
5. **Выполните вызов:** результат сохранится в переменной `my_response`.
