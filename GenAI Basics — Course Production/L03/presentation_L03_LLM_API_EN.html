Picking the next token
The model outputs candidate probabilities; temperature decides how boldly to pick beyond the first

run 3: RoboBrew
FOR CREATIVE TEXT
temperature = 1.5
The distribution flattens, less likely tokens get picked. 3 runs ➔ 3 answers.
run 1: Byte & Bean
run 2: Circuit Café
run 3: The Gear Grind
LENGTH CAP
max_output_tokens = 40
A "300-word" answer is cut at 40 tokens ➔ finish_reason = MAX_TOKENS. A guard on length and cost.
# 1.1a: the lesson's ask() helper passes temperature
ask(creative_prompt, temperature=0.0)   # repeatable
ask(creative_prompt, temperature=1.5)   # creative

# 1.1b
config=types.GenerateContentConfig(
    max_output_tokens=40,             # length cap ➔ MAX_TOKENS
    thinking_config=types.ThinkingConfig(
        thinking_level="minimal"))       # minimal…high
Rule: 0.0 for accuracy and repeatability; 0.7–1.0+ for prose and ideas. thinking_level — how much the model thinks silently; those tokens are billed too.

client = genai.Client(
    api_key=api_key,
    http_options=types.HttpOptions(
        timeout=60_000,   # 60 s, in milliseconds

# Step 1.4: catch the error instead of crashing
from google.genai import errors
try:
    client.models.generate_content(
        model="gemini-model-that-does-not-exist", contents="Ping")
except errors.APIError as e:
    print(e.code, e.status)   # 404 NOT_FOUND
Important: google-genai does not retry by default. Retries on 408 / 429 / 5xx are enabled explicitly via retry_options.

3 CORE ARCHITECTURAL TAKEAWAYS
1. LLM is a remote cloud server. No models are downloaded locally; you exchange tokens over standard HTTPS.
2. Settings are part of the code. temperature, token limit, timeout, retries and response_schema are set explicitly on every call or client.
3. Prompt patterns are code — and are checked by code. Few-Shot sets the format, CoT makes the math visible, XML separates data; validate(), ground truth and timestamp checks catch model mistakes.
