What the Server Returns: Dissecting the Digital Receipt

Alongside text, the model returns a transaction passport: finish reason and exact token accounting

OUTPUT PAYLOAD
`response.text`
Clean completion text. The SDK automatically stitches multi-candidate text parts and cleans up transport headers.
FINISH STATUS
`finish_reason`
STOP confirms regular thought completion. MAX_TOKENS signals ceiling reached before completion.
TOKEN TELEMETRY
`usage_metadata`
Audits exact consumption: prompt_token_count (input) and candidates_token_count (output) for quota oversight.
# Verification of receipt in Google Colab: m = response.usage_metadata print(f"Tokens: Prompt={m.prompt_token_count}, Output={m.candidates_token_count}, Total={m.total_token_count}") print(f"Finish Reason: {response.candidates[0].finish_reason}")

BROWSER RUNTIME
GENERATE_CONTENT_STREAM

Streaming in Code: Dissecting Real-Time SSE Generation

The `generate_content_stream` method delivers token deltas as they compute, eliminating perceived lag

# Enable real-time token streaming (Server-Sent Events): response = client.models.generate_content_stream( model="gemini-3.5-flash", contents="Explain streaming in 2 sentences." ) # Output token deltas to console without buffering: for chunk in response: print(chunk.text, end="", flush=True)
What is a `chunk`?
A lightweight socket payload containing an incremental delta—typically 1 or 2 freshly generated tokens rather than the full document.
Why `flush=True`?
Forces the system I/O buffer to flush immediately to the terminal/UI, producing the fluid real-time typewriter experience.
When NOT to Stream?
Avoid streaming for background automation, batch ETL pipelines, or strict JSON extraction. Use standard blocking calls for atomic outputs.

PROMPT ENGINEERING IN CODE
BRIDGE TO LESSON 02

From Chat to Code: Translating XML & One-Shot into API Calls

Curriculum skills become code parameters: system instructions, XML demarcation, and deterministic greedy decoding

from google.genai import types # 1. System instructions decoupled from user input (Anti-Injection) config = types.GenerateContentConfig( system_instruction="You are a strict compliance auditor. Extract facts without pleasantries.", temperature=0.0 # 0.0 = maximal determinism ) # 2. XML structure and One-Shot exemplar inside f-string: prompt = f""" <context>Inbound customer billing dispute</context> <rules>Extract disputed amount and responsible department</rules> <example> <input>Erroneously billed $500 twice for annual license</input> <output>department: billing | amount: $500</output> </example> <document>{raw_text}</document> """ response = client.models.generate_content( model="gemini-3.5-flash", contents=prompt, config=config )
1. `system_instruction` Parameter
Architecturally isolates system authority from untrusted input text. Prevents user prompt injection attempts from overriding enterprise rules.
2. XML Tags inside F-Strings
Tags like <context>, <rules>, and <document> establish unambiguous semantic boundaries for foundation models.
3. One-Shot Exemplar + `temp=0.0`
Supplying a single concrete Input ➔ Output exemplar with greedy decoding eliminates conversational fluff and guarantees consistent schemas across runs.

BROWSER RUNTIME
GUARANTEED JSON

Practical Implementation: Parsing Inbound Emails into JSON

Using `response_mime_type="application/json"` and temperature=0.0 for deterministic schema contracts

import json from google.genai import types # Constrained mode: model is physically barred from emitting non-JSON tokens config = types.GenerateContentConfig( response_mime_type="application/json", temperature=0.0 # Zero randomness, strict greedy decoding ) prompt = """ Extract ticket fields into JSON: { "category": "billing" | "technical" | "general", "urgent": true | false, "amount_usd": float } Ticket: URGENT! Card was charged twice for $450 subscription, refund immediately! """ response = client.models.generate_content( model="gemini-3.5-flash", contents=prompt, config=config ) # Parse guaranteed valid JSON directly into Python dictionary: data = json.loads(response.text) print(data["category"]) # -> "billing" print(data["amount_usd"]) # -> 450.0 print(data["urgent"]) # -> True
What Happened?
An emotional unstructured customer email was transformed into structured data fields in 1 second flat.
Why `temperature=0.0`?
Creative sampling risks hallucinating numbers. Zero temperature enforces greedy decoding and maximum determinism.
Downstream Routing
The amount_usd field directly updates ledger records, while urgent complaints escalate to billing staff automatically.

NETWORK RESILIENCE
FAULT TOLERANCE

What Can Go Wrong: 4 Common Network Failures

Connections drop, cloud providers face outages, and quotas deplete. How robust software handles failure

401 UNAUTHORIZED
Invalid Key
Key copied with trailing space, revoked, or missing in environment. Action: verify token value and access rights.
429 RATE LIMIT
Quota Reached
Exceeded requests-per-minute threshold or depleted credit tier. Action: backoff delay or tier upgrade.
500 / 503 ERROR
Provider Outage
Temporary overload in OpenAI or Google datacenters. Action: automated retry or multi-provider fallback.
TIMEOUT
Socket Stall
Packets stalled mid-transit. Without explicit timeout=30.0, applications hang indefinitely.
🛡️
Built-in Retries: Official SDKs bundle retry logic for 429 and 500 errors out of the box, saving you from writing custom retry loops.

PRODUCTION READINESS

First AI Script Checklist: 5 Core Rules

The pre-flight checklist before handing code to users or running scripts in production

1. Secret Hygiene
MANDATORY
Keys stored strictly in .env or environment variables. The .env file is explicitly tracked in .gitignore.
2. Explicit Timeouts
RESILIENCE
Always supply timeout=30.0 when initializing client instances to prevent deadlocked threads from network hangs.
3. Calibrated Temperature
ACCURACY
temperature=0.0 for JSON schemas, numbers, and classification tasks. 0.7+ only for creative prose generation.
4. Schema Enforcement
CONTRACT
Never rely on prompt pleas like "return JSON". Enforce structured contracts via the API's native response_format parameter.
5. Telemetry & Audit Logging
GOVERNANCE
Always persist response.id and usage.total_tokens to maintain financial traceability and performance audits.
