# Урок 11 • Шпаргалка: вызов функций и первый агент

**Одной фразой:** модель не знает текущих данных, поэтому ей дают инструменты: она предлагает вызов функции, ваша программа проверяет и выполняет его, результат возвращается модели; агент — это такой цикл с лимитом шагов, а рискованные действия подтверждает человек.

## Слайды и время (90 мин)
* **01 Обложка (2, 0–2).**
* **02 Проблема (4, 2–6):** без инструмента модель выдумывает статус заказа; с инструментом отвечает по данным (скриншот AI Studio).
* **03 Вы это уже видели (4, 6–10):** Claude: веб-поиск → «неубедительно» → чтение 3 страниц → ответ (Ollama v0.40.5).
* **04 Инструмент (5, 10–15):** имя, описание, параметры; модель не видит код функции.
* **05 Кто что делает (5, 15–20):** модель предлагает, программа проверяет, спрашивает человека, выполняет, логирует.
* **06 Демо, шаг 1 (5, 20–25):** AI Studio, Gemini 3.8 Flash, вызов `get_order_status(order_id="417")`.
* **07 Демо, шаг 2 (4, 25–29):** ответ функции `{"status": "on the way", "courier": "Anna", "eta_minutes": 12}` → ответ модели клиенту.
* **08 Встроенные инструменты (4, 29–33):** код, поиск, Maps, URL context; у OpenAI web_search, file_search, code_interpreter, computer, mcp; у Anthropic веб-поиск (~$10 за 1000), чтение страниц, код.
* **09 Описание (4, 33–37):** плохо `get_data`, хорошо `get_order_status` с «что, для чего, когда».
* **10 Агент (5, 37–42):** модель + инструменты + цикл; финальный ответ, когда инструмент не нужен; лимит шагов.
* **11 Код (5, 42–47):** google-genai, функция с docstring в `tools=[...]`, автоматический вызов, по умолчанию до 10 вызовов.
* **12 Локальные модели (4, 47–51):** Qwen3.5, Granite 4.2, gpt-oss-20b через Ollama/LM Studio; маленькие ошибаются чаще.
* **13 Агент собирает агента (4, 51–55):** промпт для Claude Code / Codex / Antigravity.
* **14 Рынок (4, 55–59):** ChatGPT Work, Claude, Gemini Tasks; OpenAI Agents SDK, Claude Agent SDK, Gemini API; Agent Builder закрывается 30.11.2026.
* **15 Перерыв (5, 59–64).**
* **16 Риски (5, 64–69):** prompt injection (№1 в OWASP), действие без спроса, бесконечный цикл, лишний доступ.
* **17 Надёжность (4, 69–73):** τ²-bench лучший 87,9%, τ³-bench (банк) 55,2% (решено с 1 попытки, Pass^1).
* **18 Правила (4, 73–77):** узкие инструменты, проверка в коде, человек подтверждает, лимиты и журнал.
* **19 Упражнение (5, 77–82):** 4 вопроса клиента → какой инструмент; ответы только в заметках спикера.
* **20 ДЗ (5, 82–87):** сдача в `genai-homeworks/L11/`.
* **21 Итоги (3, 87–90):** анонс L12 (MCP).

## Термины простыми словами
| Термин | Простыми словами |
|---|---|
| Инструмент (tool) | действие, которое модель может попросить: найти, посчитать, отправить |
| Вызов функции (function call) | ответ модели «вызови get_order_status с номером 417» вместо текста |
| Описание функции (declaration) | имя, описание и параметры — всё, что модель знает об инструменте |
| Граница доверия | линия между моделью (может ошибиться) и программой (проверяет и выполняет) |
| Агент | модель с инструментами, которая работает в цикле до решения задачи |
| Prompt injection | чужой текст в странице или письме, который пытается командовать моделью |
| Docstring | строка-описание функции в Python; библиотека отдаёт её модели как описание инструмента |
