# Урок 10 • Шпаргалка: открытые модели, LM Studio, RunPod

**Одной фразой:** открытая модель — это файл весов и лицензия; если файл Q4 плюс 20–30% влезает в память видеокарты, модель можно запустить у себя в LM Studio или Ollama и подключить к коду, поменяв одну строку с адресом; когда ноутбука мало — та же модель на арендованной видеокарте RunPod.

## Слайды и время (90 мин)
* **01 Обложка (2, 0–2).**
* **02 Одно приложение, три места (4, 2–6):** облачный API / ноутбук `localhost:1234` / арендованная видеокарта. Меняется адрес, не код.
* **03 Открытая модель = файл + лицензия (5, 6–11):** Hugging Face `ibm-granite/granite-4.2-8b-GGUF`, Apache-2.0, файлы 3,4–9,4 ГБ.
* **04 Зачем (4, 11–15):** плюсы и минусы; индекс Artificial Analysis 58 (Claude Opus 5.5) / 46 (MiMo-V2.6-Pro) / 34 (Qwen3.8 27B).
* **05 Пять частей (4, 15–19):** файл → движок llama.cpp → железо → сервер → приложение.
* **06 Квантизация (5, 19–24):** Granite 4.2 8B: Q2_K 3,4 · Q4_K_M 5,3 · Q8_0 9,3 · BF16 17,6 ГБ. Начинать с Q4.
* **07 Влезет ли (5, 24–29):** Q4: Granite 3B 2,2 · Qwen3.5 4B 2,7 · Granite 8B 5,3 · Qwen3.5 9B 5,6 · Gemma 4 12B 7,4 · gpt-oss-20b 12,1 · Qwen3.8 27B 16,8 ГБ. Плюс 20–30% на контекст.
* **08 Скорость (4, 29–33):** токенов/с (7B Q4, llama.cpp): CPU ≈10 (оценка), M4 24, RTX 4050 Laptop 44, M4 Max 83, RTX 4090 186, H100 268. Комфортно от 20.
* **09 LM Studio (5, 33–38):** Chat, Discover, My Models, Developer. Бесплатно и для работы. Версия 0.4.26. Не путать с Bionic.
* **10 Демо (5, 38–43):** granite-4.2-3b Q4_K_M (2,2 ГБ, скачать заранее), промпт с тикетом → JSON.
* **11 Локальный сервер (5, 43–48):** Developer → Start server, `http://localhost:1234/v1`; Ollama `http://localhost:11434/v1`. Меняются адрес и имя модели.
* **12 Агент ставит модель (4, 48–52):** промпт для Claude Code / Codex / Antigravity: Ollama, модель, скорость, только localhost.
* **13 Локально ≠ приватно (4, 52–56):** скачивание, инструменты (MCP), сервер в сети → токен.
* **14 Рынок (4, 56–60):** ноутбук / одна видеокарта / сервер; почти всё Apache-2.0; Llama 4 и Qwen3.8-Flash-Next со своей лицензией.
* **15 Перерыв (5, 60–65).**
* **16 Предел ноутбука (3, 65–68):** не влезает, медленно, много пользователей, 24/7.
* **17 RunPod (5, 68–73):** Pod (сам включил и выключил) и Serverless (просыпается по запросу). Stop всё ещё берёт за диск → Terminate.
* **18 Цена (5, 73–78):** Community за час: RTX 4090 $0.34 · 5090 $0.69 · L40S $0.79 · A100 $1.39 · H100 $2.69. 4090 при 100% загрузке ≈ $0.73 за 1 млн токенов против $0.40–4.50 у дешёвых облачных моделей.
* **19 Как выбрать (4, 78–82):** можно ли отдать данные × сколько работы → API / ноутбук / Serverless / Pod.
* **20 ДЗ (5, 82–87):** модель у себя, 3 задачи против облака, скорость, карточка выбора.
* **21 Итоги (3, 87–90):** шесть правил, анонс L11.

## Термины простыми словами
| Термин | Простыми словами |
|---|---|
| Веса, параметры | обученные числа внутри модели; «8B» = 8 миллиардов |
| Открытая модель | веса можно скачать и запустить у себя по лицензии |
| GGUF | формат файла модели для LM Studio, Ollama, llama.cpp |
| Квантизация (Q4, Q8) | сжатие: каждое число хранится меньшим числом бит |
| Видеопамять (VRAM) | память видеокарты; в неё должна влезть модель |
| Токен в секунду | скорость генерации; человек читает ≈ 5–8 |
| localhost | «этот компьютер»; сервер виден только вам |
| Pod / Serverless | арендованный компьютер с видеокартой / видеокарта по запросу |

## Перепроверить за сутки до занятия
1. Версия LM Studio, названия вкладок, «Start server», совместимые эндпоинты (lmstudio.ai/docs).
2. Тег модели в Ollama для Granite 4.2 3B и версия Ollama (ollama.com/library).
3. Размеры GGUF на Hugging Face (granite-4.2-3b/8b, Qwen3.5, Gemma 4, gpt-oss-20b).
4. Индекс Artificial Analysis (artificialanalysis.ai).
5. Цены RunPod Pods и Serverless, цена диска остановленного Pod, лимит расходов (runpod.io/pricing, docs.runpod.io).
6. Цены дешёвых облачных моделей за 1 млн токенов (Gemini, OpenAI).
7. Новые открытые модели за последний месяц (Qwen, Gemma, Granite, Llama/Muse, Mistral).
