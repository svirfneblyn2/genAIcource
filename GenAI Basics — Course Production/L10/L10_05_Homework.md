## Цели

1. Самостоятельно выбрать модель под свой компьютер и объяснить выбор: размер файла, память, лицензия.
2. Запустить модель локально и измерить скорость.
3. Сравнить локальную модель с облачной на трёх своих задачах.
4. Решить, где запускать модель для своей задачи: облачный API, ноутбук, RunPod Pod или Serverless.

Оценивается честность сравнения и аргументы, а не то, какая модель «победила».

## Шаги

### 1. Выбрать модель (15 мин)
- Узнайте свою память: *Диспетчер задач → Производительность* (ОЗУ и «Выделенная память графического процессора»). На Mac: *Об этом Mac*.
- По слайду 7 выберите модель так, чтобы файл Q4 + 20–30% влез в память видеокарты (или в ОЗУ, если видеокарты нет).
- Подсказки:
  - нет видеокарты, 16 ГБ ОЗУ → `granite-4.2-3b` (2,2 ГБ) или Qwen3.5 4B (2,7 ГБ);
  - видеокарта 6–8 ГБ → Granite 4.2 8B или Qwen3.5 9B (5,3–5,6 ГБ);
  - видеокарта 16 ГБ и больше → Gemma 4 12B (7,4 ГБ) или gpt-oss-20b (12,1 ГБ).
- Откройте карточку модели на Hugging Face и запишите лицензию.

### 2. Поставить и запустить (30–60 мин)
- **Вариант А (без командной строки):** LM Studio с lmstudio.ai. На странице загрузки возьмите обычную **LM Studio**, не Bionic. Discover → найти модель → Download (Q4_K_M) → в Chat выбрать модель.
- **Вариант Б (командная строка или агент):** Ollama с ollama.com, затем `ollama run <имя модели>`. Можно поручить установку агенту разработки промптом со слайда 12; читайте команды перед подтверждением.
- Сделайте скриншот: ответ модели и строка со скоростью (токенов в секунду). В LM Studio скорость видна под ответом; в Ollama запустите `ollama run <модель> --verbose`.
- Запишите, сколько памяти заняла модель (Диспетчер задач).

### 3. Три рабочие задачи (40 мин)
Придумайте три задачи из своей работы на **синтетических** данных (никаких настоящих писем клиентов):
1. классификация (например: тема и срочность письма);
2. выжимка (3 пункта из длинного текста);
3. ответ клиенту или черновик письма.

Отдайте каждую задачу локальной модели и ChatGPT (или Gemini, Claude) с одинаковым промптом. Оцените каждый ответ по шкале 1–5: правильность, формат, язык.

### 4. Карточка выбора (15 мин)
Для одной реальной задачи вашей команды ответьте на два вопроса со слайда 19: можно ли отдавать данные поставщику модели и сколько работы (запросов в день)? Выберите: облачный API, ноутбук, RunPod Serverless или RunPod Pod — и объясните в 3–5 предложениях.

### 5. По желанию
- Включите в LM Studio локальный сервер (Developer → Start server) и вызовите модель кодом со слайда 11. Сервер только на `localhost`.
- RunPod: только если готовы заплатить. Поставьте лимит расходов, после работы — **Terminate**, не Stop.

## Критерии оценки (10 баллов)

| Критерий | Баллы |
|---|---|
| Модель выбрана под память, расчёт «файл + 20–30%» показан, лицензия записана | 2 |
| Модель запущена, есть скриншот со скоростью и занятой памятью | 2 |
| Три задачи, одинаковые промпты, оценки 1–5 с пояснением | 3 |
| Карточка выбора с аргументами про данные и объём | 2 |
| Безопасность: синтетические данные, сервер только на localhost, модель от известного автора | 1 |

**Частые ошибки:** скачали Q8 или BF16 «для качества», и модель не влезла; не записали лицензию; сравнили разные промпты; оставили RunPod Pod в состоянии Stop.
