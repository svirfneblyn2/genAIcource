## Цели

1. Провести одну маленькую фичу курьерского приложения через неделю из урока: заметки встречи → бриф → issue → код и тесты → pull request → чек-лист релиза.
2. Использовать Copilot во всех трёх местах: Copilot Chat (документы), GitHub Copilot в VS Code (репозиторий), Copilot в Windows или бесплатный чат (ваш ПК).
3. Принимать результат по **diff и тестам**, а не по слову «готово».
4. Сохранить доказательства: три скриншота и чек-лист.

Оценивается по шести проверкам. Маленькое, проверенное и честно отмеченное изменение получает больше, чем хитрое, которое никто не проверил.

## Фича

Выберите одну:
- **Правило из урока:** «Подписчики Prime получают бесплатную доставку от заказа $75 внутри города; от $100 бесплатно для всех, как раньше; вне зоны ничего не меняется».
- **Своё правило** с числом, например «дождь: +$2 вне зоны для заказов до $40». У вашего правила **должен быть порог**, чтобы было что проверять на границе.

Всё **придуманное**: приложение, клиенты, числа.

**Исходные файлы:** скопируйте папку `demo_courier_copilot/sample_repo/` из материалов курса **без** `expected_solution/`. В ней `delivery_fee.py`, `test_delivery_fee.py` (4 теста), `ISSUE.md` (пример issue) и `.github/copilot-instructions.md`. Текст issue для своего правила напишите сами; файл инструкций можно поправить (коротко).

## Инструменты (октябрь 2026, только бесплатные)

**Бесплатные лимиты небольшие и часто меняются. Проверьте актуальные условия до начала.**

| Где | Бесплатный инструмент | Примечания |
|---|---|---|
| Бриф, заметки | **Copilot Chat** (веб, Edge или приложение Windows), заметки вставляете сами | Рабочий Microsoft 365 с Copilot в Word по желанию, не обязателен |
| Issue, PR | **github.com** (бесплатный аккаунт) | Copilot code review на бесплатных тарифах может тратить платные кредиты: комментарий человека засчитывается |
| Код | **VS Code** + **GitHub Copilot Free** (подсказки, чат, агент в ограниченном объёме) | Проверенным студентам: **Copilot Student** бесплатно. Чат и агент на Free ограничены в месяц; кончились: берите Copilot Chat в вебе, вставляйте код руками и напишите об этом в `README.md` |
| Windows | Клавиша Copilot или `Win+C`, приложение Copilot, Vision | Нет на вашем устройстве? Вставьте текст чек-листа в бесплатный чат |
| Тесты | `python -m unittest -v` (Python 3, ставить ничего не нужно) | CI по желанию: достаточно скриншота терминала |

**Не нужно и нельзя в этом задании:** облачный агент («Assign to Copilot», платный; L16), платные тарифы, данные настоящих клиентов, чужой код.

## Критерии оценки (= шесть проверок слайда 18)

| # | Проверка | Засчитывается, если |
|---|---|---|
| 1 | Бриф | каждая строка отмечена «из заметок» или «добавил Copilot»; добавленное удалено или проверено |
| 2 | Issue | в нём числа **и** что не должно меняться, и какие тесты нужны |
| 3 | Маленькое изменение | в diff ≤ 10 строк логики (тесты не считаются); новых зависимостей нет |
| 4 | Тесты | покрывают границу (значение, значение − 0.01, случай вне правила), все зелёные; видно на скриншоте или в CI |
| 5 | Ревью | у PR есть комментарий ревью (Copilot или человека) с вашим ответом; PR смержен |
| 6 | Доказательства | 3 скриншота в `README.md`; `checklist.md` называет один пункт, который остановил бы релиз |

Полнота (обязательна, отдельно не оценивается): все пять файлов на месте, репозиторий публичный, настоящих данных нет.
