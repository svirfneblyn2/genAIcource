| Зона | Аккаунт | Что видит Copilot | Плитки на слайде |
|---|---|---|---|
| **A · Для себя** | личный, бесплатно | веб и то, что вы дали: текст, файл, окно на экране | Copilot, Windows 11, Edge, Paint и Фото, Bing |
| **B · Microsoft 365** | рабочий / учебный | Copilot Chat бесплатно: веб и вставленное; с лицензией — вашу почту, файлы, встречи, чаты (только то, что открыто вам) | Word, Excel, PowerPoint, Outlook, Teams, OneNote, OneDrive, SharePoint, Loop и Pages + **агенты**: Researcher, Analyst, Cowork, Facilitator, Agent Builder |

**Ядро внутри всех:** OpenAI GPT • Anthropic Claude • Microsoft MAI + то, что Copilot видит (веб, файл, почта, экран). Иконки на слайде — упрощённые плитки, не логотипы.  
Цвет значка: зелёный — бесплатно • голубой — рабочая лицензия • жёлтый — превью • фиолетовый — подписка Microsoft 365 для дома.

### Новые слова (сл. 3)
Матрёшка изнутри наружу: каждый слой = предыдущий **+ одна новая способность**.
* **Модель (LLM)** — текст на входе → текст на выходе; сама ничего не видит и не делает (GPT, Claude, MAI — то, что вызывали из Python в L03).
* **Чат** — модель + окно разговора и память беседы: вопрос → ответ, остальное делаете вы (Copilot Chat: «объясни правило доставки»).
* **Ассистент (Copilot)** — живёт внутри приложения и **видит контекст**: файл, письмо, экран (Copilot в Word: «сократи этот абзац»).
* **Агент** — ассистент, которому разрешили действовать: сам планирует шаги, действует навыками и коннекторами, **спрашивает «да?»** (Cowork: «подготовь встречу» → письмо, файл, приглашение).

Детали конструктора: **контекст и знания** — что Copilot видит в момент ответа (открытый файл, письмо, сайт, экран) • **инструкция (промпт)** — что и как сделать: роль, правила, формат; у агента постоянная • **навык (скилл)** — готовое умение: файл Word, картинка, расчёт кодом • **коннектор** — «провод» к другому сервису: Gmail, Google Drive, SharePoint (подробно — MCP в L12).  
Формула: **агент = модель + инструкция + знания + навыки + коннекторы + право действовать**; важные шаги подтверждает у вас. На сл. 16–17 собираем агента из этих частей.

### Три уровня (сл. 4)
Copilot = **модель + то, что она видит + то, что ей разрешено**. Режим **Auto** выбирает модель сам. Запоминаем уровни, а не названия моделей.
1. **Отвечает** — чат: вопрос → текст, копируете сами.
2. **Правит документ** — Word, Excel, PowerPoint меняют файл, вы видите, что изменилось.
3. **Делает работу (агент)** — сам планирует шаги, **спрашивает разрешения** перед важным (Cowork, Researcher, Autopilot).

### Copilot в Windows (сл. 9; личный аккаунт, официально на 13.10.2026)
* **Бесплатно на любом ПК с Windows 11:** чат и голос (клавиша Copilot или **Win+C**; «Hey Copilot» — по желанию в настройках) • скриншот и **Vision**: подсвечивает, **но не кликает** • файлы: загрузить или найти на ПК • создать картинку или файл Word / Excel / PowerPoint из ответа • коннекторы OneDrive, Outlook.com, Gmail, Google Drive, Календарь — на copilot.com и в телефоне.
* **Официальные лимиты:** **20 файлов** в одном чате • **50 МБ** на файл (PDF, DOCX, XLSX, PPTX, PNG, JPEG, TXT, CSV, MD) • история чатов хранится **18 месяцев**.
* **Не опубликовано:** лимиты сообщений, длины запроса, картинок, минут голоса. Цифры вроде «15 быстрых картинок» — неофициальные. Подписка Microsoft 365 даёт «больше», без чисел.
* **Только на Copilot+ ПК** (с нейропроцессором): Click to Do, Recall, агент в Параметрах. Copilot Actions — пока только у инсайдеров.
* **Приватность:** в личном аккаунте обучение на ваших чатах **включено по умолчанию**. Выключить: профиль → Settings → Privacy → **Training on conversation activity**. Рабочие и учебные аккаунты для обучения не используются.
* **Edge:** вопросы по открытым вкладкам и истории, Journeys. Отдельный Copilot Mode закрыт в мае 2026; действия в браузере — Premium, только США.

### Свой агент: Agent Builder (сл. 16–17)
**Агент = Copilot + ваша инструкция + ваши знания.** Где: приложение Copilot, учебный / рабочий аккаунт → **Agents → New agent**. Есть **даже в бесплатном Copilot Chat** (проверили 13.10.2026 на аккаунте IT Park); ИТ-отдел может функцию выключить. Для личного аккаунта официальных подтверждений нет. Не в мобильном приложении.

| Часть агента | Что это | В бесплатном Copilot Chat |
|---|---|---|
| **Инструкция** | кто ты, как отвечаешь, чего не делаешь | ✅ |
| **Знания** | где агент ищет ответы | ✅ веб и **до 4 публичных сайтов** (до двух уровней пути, без параметров) • ❌ загруженные файлы, SharePoint, коннекторы — только если организация включила **оплату по использованию** (pay-as-you-go) • ❌ почта, Teams, люди — только с **лицензией** |
| **Навыки** | код (документы, графики) и картинки | ✅ включены сразу |
| **Стартовые вопросы** | кнопки-подсказки для пользователя | ✅ |

**Ограничения полей:** имя — **до 30 символов** • описание — **до 1 000** • инструкция — **до 8 000** символов • иконка PNG 192×192, до 1 МБ.  
**Шаги (наш запуск 13.10.2026):** описать словами («Помощник поддержки курьеров», правила Prime) → Agent Builder сам пишет имя, описание, инструкцию и 4 стартовых вопроса → **Preview**: «Prime, $80, за городом» → **$18.00** (верно); «доставка за $70?» → **переспросил зону и Prime** → **Create** → агент **личный**; поделиться — кнопка **Share** (по ссылке или с организацией, если ИТ разрешил). Правки после создания вступают в силу только после **Update**.  
Агенты Agent Builder не работают в групповых и личных чатах Teams. Для процессов, подключений к системам и публикации на сайт — **Copilot Studio** (L12).

### 5 правил урока (сл. 22)
1. Сначала спросите: **чья информация и где она лежит?** • 2. Внутри те же модели; разница в том, **что Copilot видит и что ему разрешено** • 3. Бесплатно: личный Copilot, Copilot Chat, GitHub Copilot Free • 4. Агент делает работу, но **спрашивает вашего «да»** • 5. Любой ответ — черновик: **проверяйте цифры**.

Плюс правила безопасности (сл. 20): Copilot видит только то, что можете открыть вы • рабочие данные под защитой договора (зелёный щит); в личном аккаунте **выключите обучение** • **пароли, ключи, данные клиентов в чат не вставляем** • ответ — черновик.
