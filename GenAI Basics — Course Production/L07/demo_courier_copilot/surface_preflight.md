# Before class (10 minutes)

## GitHub Copilot (VS Code)
- Sign in to VS Code with the demo GitHub account; open the Copilot chat panel.
- Clone `sample_repo` into a clean folder and run `python smoke_check.py`.
- Check that "Allow GitHub to use my data for AI model training" is off for a personal account.

## Microsoft 365 / Copilot Chat
- Sign in with the intended account. Use only `meeting_notes.md`; no real mail, chats or files.
- No licence? Paste the notes into free Copilot Chat. No access at all? Show `fallback_outputs/brief_expected.md`.

## Windows
- Check which Copilot features exist on the demo PC (key, app, Vision, file search).
- No Copilot key: use Win+C or open the app. No Vision: paste the text of `release_checklist.txt`.
