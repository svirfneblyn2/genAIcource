# Surface preflight — run before class

## GitHub Copilot
- Confirm the demo account can use Copilot in the selected IDE or CLI.
- Confirm organization policy permits the selected agent/CLI surface.
- Clone the sample_repo into a clean directory.
- Run `python smoke_check.py`.
- If demonstrating cloud agent, use a disposable GitHub repository and verify the agent policy is enabled.

## Microsoft Copilot / Microsoft 365 Copilot
- Sign in with the intended work/school account.
- Verify the UI clearly indicates the expected work context / enterprise data protection.
- If demonstrating work-data grounding, confirm the account has the required Microsoft 365 Copilot entitlement and only use the synthetic meeting-notes fixture.
- Do not use real mail, chats, customer files, or personal documents.

## Windows
- Verify which Copilot app/features are actually present on the demo PC; Windows feature availability changes by build, device and account.
- File search or Vision are optional. If absent, demonstrate the same decision principle by manually attaching/opening the synthetic `release_checklist.txt`.
- Recall and Click to Do are separate Copilot+ PC features; do not imply they exist on every Windows PC.
