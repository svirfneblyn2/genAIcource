# Lecture 07 demo assets — Copilot Ecosystem

The assets are synthetic and safe for classroom use. The point of the demo is not to prove that one assistant is “best”; it is to show how the authoritative context, account boundary and action boundary determine the correct Copilot surface.

Recommended flow:
1. `sample_repo/` — GitHub Copilot task: issue → plan → change → tests → review.
2. `meeting_notes_fixture.docx` — Microsoft 365 Copilot task: meeting decisions → rollout brief, while showing whether work-data grounding is available.
3. `release_checklist.txt` — Windows task: local file/PC context if supported, or manual attach fallback.
4. `copilot_operating_map_template.md` — student artifact.

No live demo should use real email, chats, source repositories, customer files or personal documents.
