## 2. Часть 1: Microsoft 365 Copilot (6 минут)
*Слайд презентации: 16*  
*Цель:* Показать заземление на документ встреч и формулирование промпта по 4 ингредиентам Microsoft Learn.

### Шаг 1: Открытие контекста
* В Word (или M365 Copilot Chat) прикрепите файл `meeting_notes_fixture.docx` через символ `/` или иконку скрепки.
* Проговорите аудитории: *«Мы не просим модель придумать правила из головы. Мы заземляем запрос на авторитетный протокол созвона топ-менеджмента»*.

### Шаг 2: Ввод эталонного 4-компонентного промпта
Скопируйте в поле ввода следующий промпт:

```text
[Goal]: Сформируй структурированный бриф для службы поддержки клиентов по внедрению правила бесплатной VIP-доставки.
[Context]: Мы запускаем это правило в ближайшие выходные. Операторам саппорта нужно четко понимать критерии активации скидки и исключения.
[Source]: Опирайся строго на прикрепленный файл meeting_notes_fixture.docx. Не добавляй выдуманных правил!
[Expectations]: Ответ оформи в формате Markdown с тремя разделами: 
1. Критерии предоставления бесплатной доставки;
2. Пограничные сценарии и ограничения;
3. Открытые вопросы, требующие уточнения бизнеса.
Объем — до 250 слов. Обязательно добавь цитаты первоисточника со ссылками на абзацы.
```

### Шаг 3: Что подсветить на экране студентам
1. **Порог заказа:** Обратите внимание, что модель четко зафиксировала минимальный чек в $50 для активации бесплатной доставки.
2. **Открытый вопрос:** Покажите, что Copilot обнаружил нерешенный спор в протоколе встречи — *«компенсируется ли стоимость доставки при опоздании курьера по вине погоды?»*.
3. **Цитаты первоисточника (Citations):** Покажите квадратные скобки со сносками, ведущие на абзацы исходного документа `meeting_notes_fixture.docx`.

*Если произошел сбой сети:* Мгновенно откройте вкладку `demo_assets/fallback_outputs/m365_expected_brief.md` со словами: *«На случай тайм-аута облака у нас готов сохраненный эталонный артефакт»*.

## 3. Часть 2: GitHub Copilot Agent Mode в VS Code (7 минут)
*Слайд презентации: 17*  
*Цель:* Продемонстрировать переход от чата к мультифайловому агенту с терминальным запуском тестов и контролем diff.

### Шаг 1: Обзор задачи в VS Code
* Откройте `ISSUE.md`: покажите студентам требования к классу `VIPShippingCalculator`.
* Откройте `.github/copilot-instructions.md`: обратите внимание на правило *«Always include unit tests with pytest and preserve existing public signatures»*.

### Шаг 2: Запуск Agent Mode
* Откройте панель Copilot в VS Code (комбинация `Ctrl+I` или боковой чат в режиме **Agent Mode / Copilot Edits**).
* Введите рабочий промпт:

```text
@workspace Прочитай ISSUE.md и корпоративные инструкции в .github/copilot-instructions.md.
1. Предложи план изменений для добавления правила бесплатной доставки VIP-клиентам при чеке от $50.
2. Обнови метод calculate_shipping в файле sample_repo/shipping.py.
3. Добавь граничные unit-тесты в sample_repo/test_shipping.py (VIP с чеком <$50, VIP с чеком >=$50, не-VIP).
4. Запусти команду python smoke_check.py в терминале и убедись, что все тесты зеленые.
```

### Шаг 3: Человеческий чекпоинт (Human-in-the-Loop)
1. **Инспекция плана:** Покажите студентам, что агент сначала вывел список шагов перед правкой файлов.
2. **Запрос на выполнение команды:** Обратите внимание аудитории на то, что VS Code требует явного нажатия кнопки **Approve / Allow** для выполнения shell-команды `python smoke_check.py`.
3. **Инспекция построчного diff:** Откройте предложенный diff в `shipping.py`.  
   *Спикер говорит:* *«Смотрите: я проверяю, не удалил ли агент существующую проверку на отрицательный вес посылки. Нет, существующий код сохранен, добавлена только ветка VIP. Это то, за что отвечает человек!»*.
4. Нажмите **Accept Edits** и запустите в терминале:
   ```bash
   python smoke_check.py
   ```
   Убедитесь, что количество тестов увеличилось (например, с 4 до 6), и статус равен `OK`.
