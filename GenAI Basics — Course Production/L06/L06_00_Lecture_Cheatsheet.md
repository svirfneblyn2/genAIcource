* **03 Где генерировать (4, 05–09):** чат (ChatGPT, Gemini app с Lyria 3.5) • веб-студии (ElevenLabs, Suno, Google AI Studio; здесь ДЗ) • API (OpenAI, Gemini API, Google Cloud / Azure Speech, ElevenLabs, Deepgram / AssemblyAI) • 4-й путь: открытые модели (Whisper, Kokoro, Piper, MusicGen), $0 за минуту, лицензии разные.
* **04 Четыре задачи (4, 09–13):** синтез речи (TTS) • распознавание речи (STT, ASR) • речь в речь • музыка и звуковые эффекты. Озвучка использует три из четырёх.
* **05 Принцип (4, 13–17):** текст → модель → аудиотокены → декодер → звук. Gemini считает 25 аудиотокенов/с; MusicGen 50 шагов/с; студийный звук 48 000 чисел/с. Правил чтения внутри нет → ошибки на числах, именах, сокращениях.
* **06 Звук видеомодели (4, 17–21):** Veo придумал «Here’s your order. Thank you. Have a good day.» (шот 1) и «Continue straight for 200 meters…» (неудачный клип); в промптах реплик нет. Veo 3.1 в Vertex AI: **$0.40/с со звуком, $0.20/с без** (`generateAudio`); в Gemini API звук всегда. Нужны точные слова → голос отдельно.
* **07 Шаг 1 сценарий (5, 21–26):** строка = шот: время, реплика, слов / длина, шумы, музыка. Измерено ≈2,8 слова/с (RU): быстрее плана, влезает только потому, что реплики короткие; план 1,8–2,2 (EN 2–2,5). **Шот 8 с ≈ 6 с речи.** Упражнение: реплика для шота 4, ≤12 слов.
* **08 Шаг 2 текст для голоса (5, 26–31):** 6:42 → «шесть сорок две», 417 → «четыреста семнадцать» (номер заказа по-русски обычно читают числом; решаете вы), 12 мин → «двенадцать минут». Стиль: OpenAI `instructions`, Gemini 3.8 поле `style`, ElevenLabs v3 теги `[whispers]`, словари произношений.
* **09 Шаг 3 голос (4, 31–35):** из библиотеки (Gemini 30 голосов, OpenAI 13) • по описанию • клон только с письменного согласия (ElevenLabs Instant 1–2 мин, Professional от 30 мин; открытые модели — от 3 с). Сначала прогнать сложные слова.
* **10 Шаг 4 шумы и музыка (4, 35–39):** наша подложка MusicGen (CC BY-NC: только урок). Suno v6: коммерческие права только на платных тарифах • Lyria 3.5: по условиям Google, SynthID на каждом треке, в API $0.08 за песню • ElevenLabs Music 3 с–5 мин • ElevenLabs Sound Effects ≤30 с.
* **11 Шаг 5 сведение (5, 39–44):** голос −21,0 LUFS, Veo −22,8 → итог **−14,2 LUFS, −1,9 dBTP** в готовом MP4 (AAC поднимает пик на ~0,5 дБ, поэтому лимитер ставим на −2 dB, с запасом к норме −1). Приглушение (ducking); Spotify −14, Apple Podcasts −16, EBU R128 −23; истинный пик ≤ −1 dBTP. Первый проход RU дал −0,6 dBTP → двухпроходная нормализация + лимитер. Без кода: Audacity Auto Duck → Loudness Normalization → Limiter.
* **12 Шаг 6 проверка (6, 44–50):** Whisper small на итоговом звуке. RU: «Часть 42» вместо «Шесть сорок две», «Оно» вместо «Анна» — ошибки голоса, критичных слов 2/4. EN: «Here’s your order» пробивается из звука Veo, «642» — формат распознавания → 4/4 после прослушивания. Сценарий в промпт распознавания не вставлять.
* **13 Локальные модели (4, 50–54):** карточка модели и файлы весов на Hugging Face → кэш на диске → Python-пакет → процессор или видеокарта → WAV, без интернета. Kokoro 0,36 ГБ и Whisper small работают на процессоре ноутбука (наша озвучка и проверка). Qwen3-TTS 0.6B: 2,5 ГБ, на процессоре ≈8–9× медленнее реального времени (наш замер); 1.7B: 4,5 ГБ, видеокарта от 8 ГБ (сторонние замеры). $0 за минуту, но железо, электричество, время на установку; локально выгодно для приватности, постоянного объёма, экспериментов. Архитектуры (файл / поток / агент) только в заметках.
* **14 Рынок (4, 54–58):** см. слайд. Open ASR Leaderboard (Hugging Face): лучшие системы ≈4–5% ошибок в словах (английский), Whisper large-v3 ≈7–8%; лидеров перед занятием смотреть на сайте. Речь в речь: OpenAI gpt-realtime-2.1 и gpt-live-1. OpenAI отключает tts-1 / gpt-4o-mini-tts **06.01.2027**, whisper-1 / gpt-4o-transcribe **26.02.2027**.
