## Цель задания

Закрепить на реальной задаче ключевые навыки работы с генеративным звуком:
1. Синтезировать выразительный закадровый голос диктора с точным интонированием и паузами.
2. Сгенерировать предметные фоли-шумы (Foley SFX), идеально попадающие в движение объектов в кадре.
3. Создать атмосферный инструментальный саундтрек без вокала.
4. Свести 3 дорожки по стандартам громкости с применением приглушения музыки (Sidechain Ducking).
5. Провести инженерный QA-аудит качества звука (клиппинг, фазовый шум, дрейф интонации).

## Обязательная инженерная программа (3 стема)

| Стем | Что сделать | Требования к качеству |
| :--- | :--- | :--- |
| **1. Voiceover (TTS)** | Сгенерировать 1 лаконичную фразу диктора (10–15 слов). | Без металлических призвуков; естественные паузы дыхания (`...`); целевая громкость -14 LUFS. |
| **2. Foley SFX** | Сгенерировать предметные шумы по 3-слотовой формуле. | Звук должен совпадать по таймингу с визуальным событием (брызги лужи, стук кружки, пар); громкость -18 LUFS. |
| **3. Music (Suno/Udio)** | Сгенерировать инструментальный трек. | Обязательно режим **Instrumental**; автоматическое приглушение (ducking) на -4...-6 дБ во время речи диктора; громкость -22 LUFS. |
