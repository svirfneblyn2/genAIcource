### Стартовый проект (путь А)

Создайте папку `genai-homeworks/L16/` и положите в неё три файла ниже. Нужен Python 3.10+ и pytest: `pip install pytest`.

`app.py`
```python
TICKETS = [
    {"id": 1, "title": "Cannot log in", "status": "open", "priority": "high"},
    {"id": 2, "title": "Typo on the home page", "status": "open", "priority": "low"},
    {"id": 3, "title": "Export to Excel is slow", "status": "closed", "priority": "medium"},
    {"id": 4, "title": "Payment page error", "status": "open", "priority": "high"},
]


def filter_tickets(tickets, status=None):
    """Return the tickets with the given status (all tickets if status is None)."""
    if status is None:
        return list(tickets)
    return [t for t in tickets if t["status"] == status]
```

`tests/test_filter.py`
```python
from app import TICKETS, filter_tickets


def test_filter_by_status():
    ids = [t["id"] for t in filter_tickets(TICKETS, status="open")]
    assert ids == [1, 2, 4]


def test_no_filter_returns_all():
    assert len(filter_tickets(TICKETS)) == 4


def test_filter_by_priority():
    ids = [t["id"] for t in filter_tickets(TICKETS, priority="high")]
    assert ids == [1, 4]
```

`pytest.ini` (чтобы тесты нашли `app.py`)
```ini
[pytest]
pythonpath = .
```

Запустите `pytest -q` (или `python -m pytest -q`). До работы агента вы увидите, что новый тест падает, а два старых проходят:

```
..F                                                                      [100%]
FAILED tests/test_filter.py::test_filter_by_priority - TypeError: filter_tick...
1 failed, 2 passed
```

Это и есть «тест, который падает» со слайда 9. Задача для агента: сделать так, чтобы прошли все три теста, не ломая старые. **pytest -q** — команда, которая запускает все тесты; **тест** — маленькая программа, проверяющая, что код делает нужное.

## Задание

1. **AGENTS.md** (или CLAUDE.md / GEMINI.md, если этого требует ваш инструмент): команды тестов и запуска, где лежит код, что не трогать.
2. **TASK.md:** цель, что не трогать, «готово, когда…», команда проверки, кто принимает решение.
3. **План:** запустите агента в режиме плана (plan mode или аналог) и вставьте план или короткую выдержку из разговора в `AGENT_EVIDENCE.md` (раздел «План агента»).
4. **Правки в отдельной ветке** (или worktree). Режим разрешений — не выше auto; никаких рабочих ключей и паролей в папке.
5. **Проверка:** сами запустите команду из TASK.md и прочитайте diff. Сохраните вывод команды или скриншот (`check.png`). На пути В проверка — скриншот страницы README.
6. **AGENT_EVIDENCE.md:** какой агент и где запускали, план агента и одобрили ли его, какие файлы изменились, какие команды запускали и с каким результатом, новые зависимости, что нашли при ревью, оставшиеся риски и решение: **ПРИНЯТЬ / ОТКЛОНИТЬ / ПОВТОРИТЬ**.

Отклонённый патч с хорошим объяснением, что не так и что вы поменяли в задаче, — тоже отличный результат.

**Где взять агента бесплатно:** Codex в ChatGPT (есть и в бесплатном плане), GitHub Copilot Free, Google Antigravity. **Нельзя:** рабочие ключи, закрытый код компании без разрешения, режим без проверок (bypass, `--yolo` — флаг некоторых агентов командной строки, который отключает все вопросы о разрешениях) вне одноразового контейнера.

```
genai-homeworks/L16/
├─ AGENTS.md
├─ TASK.md
├─ AGENT_EVIDENCE.md      (план агента + решение)
├─ check.png
└─ app.py, pytest.ini, tests/   (только на пути А)
```

## Оценка (10 баллов)

| Критерий | Баллы |
|---|---|
| TASK.md: проверяемое «готово, когда» и границы | 3 |
| AGENTS.md: конкретные команды и запреты | 2 |
| Изменение маленькое, в отдельной ветке, без лишних правок | 2 |
| Проверка запущена вами, есть вывод или скриншот | 2 |
| Решение с объяснением и оставшимися рисками | 1 |

**Частые ошибки:** «сделай удобно» вместо проверяемого условия; агент правил всё подряд (например, переписал тесты, чтобы они проходили); «тесты прошли» без вывода команды; работа прямо в main.
