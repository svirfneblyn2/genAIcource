# Урок 08 • Ранбук живого демо: от грязного CSV к проверенному ответу

**Слайд:** 10 (после перерыва) • **Время:** 10 минут • **Запасной путь:** 3 минуты
**Файл:** `demo_assets/northstar_sales_messy.csv` (73 строки, вымышленные данные)
**Сервис:** любой из ChatGPT (анализ данных), Claude (code execution and file creation), Gemini — тот, что открыт в вашем рабочем аккаунте.
**Эталон:** `demo_assets/reference_analysis.py` → `demo_assets/local_outputs/`

## За 10 минут до занятия

1. Откройте чат-ассистента в **рабочем** аккаунте, начните новый чат. Проверьте, что загрузка файлов работает (у ChatGPT Free — 3 загрузки в день).
2. Положите `northstar_sales_messy.csv` на рабочий стол.
3. В терминале: `cd demo_assets && python reference_analysis.py` — должны появиться 4 файла в `local_outputs/` и строка `Total revenue (deduplicated) = $256,045.00`.
4. Держите открытыми `fallback_outputs/` (готовые графики) и этот ранбук.
5. **Teams:** делитесь окном браузера, а не всем экраном. Масштаб страницы — 125–150 %, чтобы таблицы читались.

## Шаг 1 — профиль (2 мин)

Загрузите файл. Промпт:

```
Опиши этот файл: что такое одна строка, сколько строк и уникальных order_id,
где пропуски, странные форматы и невозможные значения. Ничего пока не исправляй.
```

**Показать:** раскройте код (ChatGPT — кнопка рядом с ответом; Claude — блок анализа; Gemini — «показать код»).
**Ищем:** 73 / 72, четыре проблемы. Если модель уже что-то «почистила» — попросите вернуть как было и сначала только описать.

## Шаг 2 — правки (2 мин)

```
Раздели найденные проблемы на две группы:
А) механические правки, которые не меняют смысл данных;
Б) правки, которые меняют смысл. Что предлагаешь для каждой? Пока ничего не меняй.
```

**Ищем:** дубль, пустой регион, дата — в группе А; строка 1055 — в группе Б, «оставить и пометить».
**Если модель предлагает заменить 66 на 6:** не прячьте — это лучший момент урока. Спросите: «Откуда ты знаешь правильное значение?» и покажите `northstar_sales_truth.csv`: там 4.

## Шаг 3 — расчёт и график (3 мин)

```
Сделай правки группы А и запиши их в журнал. Строку 1055 оставь как есть и пометь.
Посчитай выручку по месяцам и по каналам. Построй один линейный график выручки по месяцам.
Сверь: сумма по месяцам = сумма по каналам = общий итог. Покажи код.
```

**Ищем:** итог $256,045, график растёт с 32.7 до 53.9 тыс., сверка явно выведена.
**Ручная точка вслух:** найдите в CSV строку 1063 — Search, июнь, $5,425.

| Проблема | Что делать |
