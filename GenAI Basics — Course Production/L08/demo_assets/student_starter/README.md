# Module 08 — Verified Analysis Pack

Your deliverable is not just an answer. Submit an evidence pack:

1. `cleaning_log.md` — row counts, duplicates, missing values, suspicious domain values, and every cleaning decision.
2. `analysis_brief.md` — 3–5 verified findings, each with metric definition and scope.
3. `chart.png` — one chart that supports one finding; title and units must be explicit.
4. `cleaned_data.csv` — or a reproducible transformation script if you are not allowed to redistribute data.
5. `verification.md` — at least three independent checks, plus one claim you deliberately refused to make from the data.

Use `northstar_sales_messy.csv` as the practice dataset unless your instructor supplies another one.
