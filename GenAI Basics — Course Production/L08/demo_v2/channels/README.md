# Учебная выборка «Кулинарные YouTube-каналы» (L08)

Замороженный обезличенный срез из рабочей базы автора (проект what-to-shoot, Postgres).
Собран 2026-10-17 скриптом `make_channels_sample.py`. Нужен для слайдов L08: на слайдах
показываем только графики и итоговые цифры, файлы целиком не раздаём.

## Почему выборка, а не вся база («файл не влезает»)

| Таблица в полной базе | Строк |
|---|---:|
| channels (каналы) | 26 544 |
| videos (видео) | 416 809 |

## Таблица `channels`: одна строка = один канал

| Колонка | Что значит |
|---|---|
| channel_id | условный номер канала (`ch_0001`…), к YouTube не привязан |
| title | название канала (публичное) |
| niche | тематическая подборка автора: Супы, Выпечка: пироги и бисквиты, Печенье и десерты (DE), Хлеб и дрожжевая выпечка, Гриль и костёр |
| country | страна из профиля канала (код из 2 букв); пусто у 44% |
| language | язык канала (en, de, es, ru, fr…); пусто у 39% |
| subscriber_count | подписчиков (YouTube округляет до 3 значащих цифр) |
| view_count | просмотров у канала за всё время |
| video_count | видео на канале за всё время (по данным YouTube) |
| size_bucket | размер канала: `1: <10k`, `2: 10k-100k`, `3: 100k-1M`, `4: 1M+` подписчиков |
| channel_created | дата создания канала; пусто у 26% |
| videos_in_db | сколько видео канала было в базе автора (до отбора 25 штук) |
| uploads_per_month | среднее число видео в месяц за всю жизнь канала = video_count / возраст канала |
| stats_date | когда снимались цифры канала |

## Таблица `videos`: одна строка = одно видео

| Колонка | Что значит |
|---|---|
| video_id | условный номер видео (`v_000001`…) |
| channel_id | канал, к которому относится видео (ссылка на `channels`) |
| title | название видео (почищено, см. ниже) |
| published_date | дата публикации; **пусто у 63%** (сборщик часто её не получал) |
| duration_seconds | длительность в секундах; пусто у 5% |
| duration_bucket | группа длительности: до 1 мин, 1-5, 5-10, 10-20, 20-40, 40+ мин |
| is_short | Shorts: так отметил сборщик или длительность не больше 60 секунд |
| views | просмотров на дату последнего замера |
| likes, comments | лайки и комментарии; есть только у 7% видео |
| stats_date | дата последнего замера просмотров |
| age_days | возраст видео в днях на дату замера (если известна дата публикации) |

## Периоды

- Видео опубликованы с 2007-11-06 по 2026-10-07 (по тем 37%, у кого дата известна; половина из них — 2026 год).
- Просмотры замерены с 2026-08-25 по 2026-10-07; цифры каналов — с 2026-08-23 по 2026-10-07.

## Как отбирали

1. Только каналы, которые автор вручную подтвердил как «наши» хотя бы в одной кулинарной подборке
   (состояние `selected`), с известными подписчиками и просмотрами.
2. У канала должно быть не меньше 10 видео с замером просмотров. Таких каналов 1 943 — взяли все.
3. У каждого канала — до 25 видео в псевдослучайном порядке (не только самые новые).
4. Для каждого видео — последний замер просмотров.

## Обезличивание

- Удалены описания, превью, ссылки, все внутренние и YouTube-идентификаторы. Номера `ch_`/`v_`
  выданы заново, таблицы соответствия нет.
- Из названий удалены e-mail, ссылки и домены (50 шт.), номера, похожие на телефон (10),
  и вставленные в название чужие ID видео (9). E-mail в итоговых файлах нет (проверено поиском).
- Названия каналов оставлены: это публичные имена, автор разрешил.
- Не выгружались логи LLM, ключи, квоты и личная аналитика автора.

## Оговорки (обязательно проговорить на уроке)

- **Это не весь YouTube.** Каналы найдены поиском автора по его темам (супы, выпечка, немецкая
  выпечка). Немецких каналов и выпечки больше, чем в среднем по YouTube.
- **Систематическая ошибка выжившего.** В выборке только каналы, которые нашлись и прошли ручной
  отбор, и только видео, которые сборщик успел замерить.
- **Просмотры — это снимок.** Старое видео копило просмотры годами, новое — неделями. У 63% видео
  дата публикации неизвестна, поэтому поправку на возраст сделать нельзя.
- **Маленьких каналов большинство** (1 311 из 1 943 меньше 10 тыс. подписчиков). Поэтому сравниваем
  медианы, а не средние.
- `uploads_per_month` — среднее за всю жизнь канала, а не «сейчас».
- Лайки и комментарии почти пустые: для выводов не использовать.
